# 6. Visual Intuition and Mermaid Diagram

The transformation pipeline from a raw feature to a probability prediction relies entirely on this mathematical chain.

```mermaid
flowchart TD
    A[Feature: Delta X = +1] --> B[Linear Space: Add Beta]
    B -->|exp| C[Odds Space: Multiply by e^Beta]
    C -->|Odds / 1+Odds| D[Probability Space: Non-linear Shift]
    
    subgraph Example Data: Beta = 0.5
    B1[Log-Odds + 0.5]
    C1[Odds * 1.65]
    D1[Prob approaches 1 S-Curve]
    end
    
    B -.-> B1
    C -.-> C1
    D -.-> D1
```
