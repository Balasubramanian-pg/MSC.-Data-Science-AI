# 5. Step-by-Step Derivations

### Derivation for the Gaussian Distribution
Assume $X \sim \mathcal{N}(\mu, \sigma^2)$. The PDF is $f(x|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$.

1.  **Construct Log-Likelihood**:
    $$\ell(\mu, \sigma^2) = \sum_{i=1}^n \left[ -\frac{1}{2}\ln(2\pi) - \frac{1}{2}\ln(\sigma^2) - \frac{(x_i-\mu)^2}{2\sigma^2} \right]$$
    $$\ell(\mu, \sigma^2) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i-\mu)^2$$

2.  **Differentiate with respect to $\mu$ and set to zero**:
    $$\frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum_{i=1}^n (x_i-\mu) = 0 \implies \sum_{i=1}^n x_i - n\mu = 0$$
    $$\hat{\mu}_{MLE} = \frac{1}{n}\sum_{i=1}^n x_i$$

3.  **Differentiate with respect to $\sigma^2$ and set to zero**:
    $$\frac{\partial \ell}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2}\sum_{i=1}^n (x_i-\mu)^2 = 0$$
    $$\hat{\sigma}^2_{MLE} = \frac{1}{n}\sum_{i=1}^n (x_i-\hat{\mu})^2$$

> [!NOTE]
> The MLE for variance $\hat{\sigma}^2_{MLE}$ divides by $n$, making it a biased estimator. The unbiased sample variance divides by $n-1$ (Bessel's correction). However, MLE is preferred in asymptotic theory and machine learning due to its optimal large-sample properties.
