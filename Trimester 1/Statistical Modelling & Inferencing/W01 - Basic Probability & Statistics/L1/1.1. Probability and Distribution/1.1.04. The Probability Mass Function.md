# 1.1.4. The Probability Mass Function

A probability distribution describes exactly how probability is spread across all possible values of a random variable. 

<img width="1024" height="768" alt="image" src="https://github.com/user-attachments/assets/c472c686-8995-45ed-900c-598ca0e3218d" />

For discrete random variables, this distribution is defined by the **Probability Mass Function**. <BR>
The Probability Mass Function assigns an exact, calculable probability to every specific isolated value that the discrete random variable can take.

$$P(X = x_i) = p(x_i)$$

where:

- $$P$$ = the mathematical probability
- $$X$$ = the discrete random variable
- $$x_i$$ = a specific numerical outcome
- $$p(x_i)$$ = the probability mass function evaluated at that specific outcome

Repeating the foundational Probability Mass Function equation for absolute emphasis:

$$P(X = x_i) = p(x_i)$$

>[!Note]
> This function is bound by two absolute mathematical constraints. 

First, every individual probability must be _greater than or equal to zero and less than or equal to one_. <br>
Second, the sum of all individual probabilities across the _entire sample space must equal exactly one_:

$$\sum_{i} p(x_i) = 1$$
