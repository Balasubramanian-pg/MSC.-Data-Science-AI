# 8.4. Global Explainability and Feature Importance

## 8.4.1. The Paradigm Shift from Local to Global

Transitioning from local explanations to global explanations requires a fundamental shift in perspective. Local explainability focuses on a single prediction, answering why a specific instance was classified in a certain way. Global explainability focuses on the entire dataset and model, answering what drives predictions overall.

The following table contrasts the two levels of explainability.

| Type | Scope | Question Answered |
|:---|:---:|:---|
| Local Explainability | One sample | Why was THIS prediction made? |
| Global Explainability | Entire dataset/model | What drives predictions overall? |

## 8.4.2. The Core Intuition of Global Explainability

Global explainability seeks to understand how the model behaves overall across the entire dataset. Suppose a model uses Age, Salary, and Income to predict loan approval. Global explainability asks which feature influences the prediction most across all samples.

This high-level model understanding provides trust, feature ranking, policy insight, and debugging capability. It answers the fundamental question of what the model is learning overall, rather than merely justifying a single output.

## 8.4.3. Feature Selection and Importance

The first major global explanation method is feature importance, which measures how important each feature is for prediction quality. To determine this, we often rely on feature selection strategies that evaluate prediction sensitivity.

### 3.1 Forward Selection

Forward selection is a greedy search strategy that builds the feature set incrementally.

**Step 1**: Start with an empty set of features.
**Step 2**: Add one feature at a time and evaluate the model performance for each individual feature.
**Step 3**: Build feature subsets by adding the best-performing feature to the set and evaluating combinations.
**Step 4**: Compare performance across subsets.

The key insight is that if adding a feature greatly improves performance, that feature is important.

### 3.2 Backward Elimination

Backward elimination is the opposite strategy.

**Step 1**: Start with all available features.
**Step 2**: Remove features one by one.
**Step 3**: Observe the change in model performance.

If removing a feature causes a major performance drop, the feature is important. If it causes little or no change, the feature is weak.

## 8.4.4. The Computational Challenge of Feature Search

Exhaustive feature search is computationally expensive. For $$n$$ features, there are $$2^n$$ possible subsets. This exponential growth makes brute force search intractable for large feature spaces.

To emphasize the computational complexity, we state the number of subsets:

$$
\text{Total Subsets} = 2^n
$$

where:

- $$n$$ = number of features

Because of this exponential explosion, practical systems use greedy search, heuristics, and approximation methods rather than brute force search. To reiterate the fundamental limitation of exhaustive search:

$$
\text{Total Subsets} = 2^n
$$

## 8.4.5. Tree-Based Feature Importance

Decision trees and tree-based machine learning systems provide a natural mechanism for calculating feature importance through impurity reduction.

### 5.1 Information Gain and Entropy

Entropy measures the disorder or uncertainty in a dataset. Features that reduce uncertainty the most are considered the most important.

The concept of information gain quantifies this reduction. Conceptually, more uncertainty reduction leads to higher importance. Lower entropy after splitting indicates a better feature, a cleaner separation, and higher predictive value.

The information gain from splitting a dataset $$D$$ on a feature $$A$$ is defined as:

$$
\text{Gain}(D, A) = \text{Entropy}(D) - \sum_{v \in \text{Values}(A)} \frac{|D_v|}{|D|} \text{Entropy}(D_v)
$$

where:

- $$\text{Gain}(D, A)$$ = information gain from feature $$A$$
- $$\text{Entropy}(D)$$ = entropy of the original dataset
- $$D_v$$ = subset of $$D$$ where feature $$A$$ has value $$v$$
- $$|D|$$ = total number of instances in $$D$$

To emphasize the information gain formula, we restate it:

$$
\text{Gain}(D, A) = \text{Entropy}(D) - \sum_{v \in \text{Values}(A)} \frac{|D_v|}{|D|} \text{Entropy}(D_v)
$$

## 8.4.6. SHAP Aggregation for Global Explanations

While SHAP was introduced as a local explainability method, it can be extended to provide global explanations through aggregation.

### 6.1 Extending SHAP Globally

Suppose a dataset has $$N$$ samples. The process for global SHAP involves computing SHAP values for every sample, aggregating them intelligently, and analyzing overall contribution patterns.

Global importance emerges from the average influence across many predictions. The global importance of a feature $$j$$ is calculated as the mean of the absolute SHAP values across all $$N$$ samples:

$$
\text{Global Importance}(j) = \frac{1}{N} \sum_{i=1}^{N} |\phi_{i,j}|
$$

where:

- $$\text{Global Importance}(j)$$ = global importance of feature $$j$$
- $$N$$ = total number of samples
- $$\phi_{i,j}$$ = local SHAP value for feature $$j$$ in sample $$i$$

To emphasize the global SHAP aggregation formula, we restate it:

$$
\text{Global Importance}(j) = \frac{1}{N} \sum_{i=1}^{N} |\phi_{i,j}|
$$

SHAP bridges local and global explainability because local SHAP explains one prediction, while aggregated SHAP explains overall behavior.

## 8.4.7. Limitations of Global Feature Importance

While global feature importance provides valuable insights, several critical caveats must be acknowledged.

**Correlated Features**: Highly correlated variables can distort importance rankings. For example, if Salary and Income are both included, they may share predictive signal, artificially diluting the importance of each.

**Feature Interaction Complexity**: Simple importance scores may miss nonlinear interactions and joint dependencies between features.

**Importance Does Not Imply Causality**: A feature being important does not mean the feature causes the outcome. It may only correlate strongly with the target variable.

**Model Dependency**: Different models may assign different importance rankings to the same features, reflecting the specific inductive biases of the algorithm rather than an absolute ground truth.

>[!Warning]
> Global explainability helps detect **data leakage, bias, shortcut learning, and spurious correlations**. If a loan model heavily depends on a proxy variable like ZIP code, global importance will reveal this potential socioeconomic bias.

## 8.4.8. Example of Computing Global Feature Importance

To solidify the mathematical concepts of global explainability, we apply the aggregation formula to a concrete scenario.

Suppose:

- A dataset with $$N = 4$$ samples.
- We have computed the local SHAP values for a specific feature, Age ($$\phi_{i, \text{Age}}$$), for each sample.
- The local SHAP values for Age are: 0.2, -0.4, 0.1, -0.3.
- We want to compute the global importance of Age.

### Step 1: Identify the Local SHAP Values

The local SHAP values for the 4 samples are:

$$
\phi_{1} = 0.2
$$

$$
\phi_{2} = -0.4
$$

$$
\phi_{3} = 0.1
$$

$$
\phi_{4} = -0.3
$$

### Step 2: Compute the Absolute Values

Take the absolute value of each local SHAP value:

$$
|\phi_{1}| = |0.2| = 0.2
$$

$$
|\phi_{2}| = |-0.4| = 0.4
$$

$$
|\phi_{3}| = |0.1| = 0.1
$$

$$
|\phi_{4}| = |-0.3| = 0.3
$$

### Step 3: Sum the Absolute Values

$$
\sum_{i=1}^{4} |\phi_{i}| = 0.2 + 0.4 + 0.1 + 0.3 = 1.0
$$

### Step 4: Divide by the Number of Samples

$$
N = 4
$$

$$
\text{Global Importance} = \frac{1.0}{4} = 0.25
$$

### Step 5: State the Final Result

The global importance of the Age feature is **0.25**.

## 8.4.9. Conclusions

Global explainability extends the principles of explainable artificial intelligence from individual predictions to entire model behavior. It is fundamentally about influence attribution, answering which variables control prediction behavior most strongly.

### 9.1. Summary of Global Explainability Methods

The following table summarizes the primary methods used to achieve global explainability.

| Method | Purpose | Core Mechanism |
|:---|:---:|:---|
| Forward/Backward Selection | Rank influential features | Evaluate prediction sensitivity |
| Tree-Based Importance | Rank influential features | Measure impurity reduction |
| Aggregated SHAP | Global influence analysis | Average absolute local contributions |

### 9.2. The Dual Requirement of Modern AI

Modern artificial intelligence systems increasingly require both strong predictive accuracy and strong interpretability. Explainability is not only about trust; it is also about understanding what the model has actually learned. Unexplainable intelligence becomes difficult to trust, regulate, debug, and deploy safely.

>[!Tip]
> Always validate your global feature importance rankings against domain knowledge. If the model assigns the highest importance to a feature that has no logical connection to the target, you have likely discovered data leakage or a spurious correlation.
