# 8.2.4. Scatter Plots and Correlation Analysis

<img width="1368" height="840" alt="image" src="https://github.com/user-attachments/assets/7040192a-f6e3-48bf-95e3-185fedb64658" />

Transitioning from univariate distributions to bivariate relationships, we use scatter plots to study the relationship between two numerical variables. Each point on a scatter plot represents a single observation, allowing us to visualize how variables move together.

Correlation measures the strength and direction of the linear relationship between two variables. The Pearson correlation coefficient $$r$$ is calculated as:

$$r = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2 \sum_{i=1}^{n} (y_i - \bar{y})^2}}$$

where:
- $$r$$ = Pearson correlation coefficient
- $$x_i, y_i$$ = individual observations
- $$\bar{x}, \bar{y}$$ = sample means
- $$n$$ = number of observations

To emphasize the correlation coefficient formula, we restate it:

$$r = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n} (x_i - \bar{x})^2 \sum_{i=1}^{n} (y_i - \bar{y})^2}}$$

<img width="474" height="355" alt="image" src="https://github.com/user-attachments/assets/b3c0e4bd-ebd2-46ed-a067-974d69bb09f4" />

The coefficient is strictly bounded by: $$-1 \leq r \leq 1$$

- A **positive correlation** occurs when an increase in one variable corresponds to an increase in the other. A strong positive correlation approaches $$r = 1$$.
- A **negative correlation** occurs when an increase in one variable corresponds to a decrease in the other. A strong negative correlation approaches $$r = -1$$.
- **No correlation** exists when the variables show no consistent relationship, resulting in a random scatter pattern with $$r$$ near $$0$$.

>[!Warning]
> Correlation does not imply causation. Two variables moving together mathematically does not mean one causes the other; they may both be driven by a hidden confounding variable.
