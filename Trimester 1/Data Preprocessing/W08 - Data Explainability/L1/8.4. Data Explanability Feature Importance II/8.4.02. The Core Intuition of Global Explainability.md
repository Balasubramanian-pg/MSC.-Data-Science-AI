# 8.4.2. The Core Intuition of Global Explainability

Global explainability seeks to understand how the model behaves overall across the entire dataset. Suppose a model uses Age, Salary, and Income to predict loan approval. Global explainability asks which feature **influences the prediction most across all samples**.

This high-level model understanding provides trust, feature ranking, policy insight, and debugging capability. It answers the fundamental question of what the model is learning overall, rather than merely justifying a single output.
