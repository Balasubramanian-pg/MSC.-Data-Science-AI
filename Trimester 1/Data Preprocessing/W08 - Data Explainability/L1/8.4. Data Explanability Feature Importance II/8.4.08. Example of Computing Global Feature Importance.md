# 8.4.8. Example of Computing Global Feature Importance

To solidify the mathematical concepts of global explainability, we apply the aggregation formula to a concrete scenario.

Suppose:

- A dataset with $$N = 4$$ samples.
- We have computed the local SHAP values for a specific feature, Age ($$\phi_{i, \text{Age}}$$), for each sample.
- The local SHAP values for Age are: 0.2, -0.4, 0.1, -0.3.
- We want to compute the global importance of Age.

### Step 1: Identify the Local SHAP Values

The local SHAP values for the 4 samples are:

$$
\phi_{1} = 0.2
$$

$$
\phi_{2} = -0.4
$$

$$
\phi_{3} = 0.1
$$

$$
\phi_{4} = -0.3
$$

### Step 2: Compute the Absolute Values

Take the absolute value of each local SHAP value:

$$
|\phi_{1}| = |0.2| = 0.2
$$

$$
|\phi_{2}| = |-0.4| = 0.4
$$

$$
|\phi_{3}| = |0.1| = 0.1
$$

$$
|\phi_{4}| = |-0.3| = 0.3
$$

### Step 3: Sum the Absolute Values

$$
\sum_{i=1}^{4} |\phi_{i}| = 0.2 + 0.4 + 0.1 + 0.3 = 1.0
$$

### Step 4: Divide by the Number of Samples

$$
N = 4
$$

$$
\text{Global Importance} = \frac{1.0}{4} = 0.25
$$

### Step 5: State the Final Result

The global importance of the Age feature is **0.25**.
