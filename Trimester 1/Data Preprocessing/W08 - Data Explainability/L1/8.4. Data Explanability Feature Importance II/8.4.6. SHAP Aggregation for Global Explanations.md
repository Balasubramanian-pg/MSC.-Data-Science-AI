# 8.4.6. SHAP Aggregation for Global Explanations

While SHAP was introduced as a local explainability method, it can be extended to provide global explanations through aggregation.

### 6.1 Extending SHAP Globally

Suppose a dataset has $$N$$ samples. The process for global SHAP involves computing SHAP values for every sample, aggregating them intelligently, and analyzing overall contribution patterns.

Global importance emerges from the average influence across many predictions. The global importance of a feature $$j$$ is calculated as the mean of the absolute SHAP values across all $$N$$ samples:

$$
\text{Global Importance}(j) = \frac{1}{N} \sum_{i=1}^{N} |\phi_{i,j}|
$$

where:

- $$\text{Global Importance}(j)$$ = global importance of feature $$j$$
- $$N$$ = total number of samples
- $$\phi_{i,j}$$ = local SHAP value for feature $$j$$ in sample $$i$$

To emphasize the global SHAP aggregation formula, we restate it:

$$
\text{Global Importance}(j) = \frac{1}{N} \sum_{i=1}^{N} |\phi_{i,j}|
$$

SHAP bridges local and global explainability because local SHAP explains one prediction, while aggregated SHAP explains overall behavior.
