# Practice Quiz

# Question 1

Which phase of the Data Science lifecycle focuses on understanding the business problem before analyzing the data?

## Options

* Model Deployment
* Business Understanding
* Data Visualization
* Feature Engineering

## Answer

✅ **Business Understanding**

> [!NOTE]
> **Reason**
>
> Every Data Science project begins with **Business Understanding**. This phase defines the business objective, identifies success criteria, and ensures the project solves a meaningful real-world problem before any technical work begins.

# Question 2

Which of the following is considered structured data?

## Options

* Tweets from Twitter
* Images collected from cameras
* A customer table stored in a relational database
* Audio recordings

## Answer

✅ **A customer table stored in a relational database**

> [!NOTE]
> **Reason**
>

# Question 4

Which stage of the KDD process prepares raw data for analysis by correcting errors and inconsistencies?

## Options

* Model Evaluation
* Data Cleaning and Preprocessing
* Knowledge Presentation
* Deployment

## Answer

✅ **Data Cleaning and Preprocessing**

> [!NOTE]
> **Reason**
>

# Question 10

Which of the following best describes Big Data?

## Options

* A dataset that fits easily into spreadsheet software.
* Data that can only be analyzed using SQL.
* Extremely large and complex datasets that require specialized tools and technologies.
* Any dataset containing more than one thousand records.

## Answer

✅ **Extremely large and complex datasets that require specialized tools and technologies.**

> [!NOTE]
> **Reason**
>

# Question 11

Which of the following best describes the difference between Data Science and Business Intelligence (BI)?

## Options

* Data Science only creates dashboards, while BI builds machine learning models.
* BI focuses on descriptive analytics, while Data Science also includes predictive and prescriptive analytics.
* BI is used only for financial data.
* There is no difference between Data Science and BI.

## Answer

✅ **BI focuses on descriptive analytics, while Data Science also includes predictive and prescriptive analytics.**

> [!NOTE]
> **Reason**
>
> Business Intelligence primarily answers **"What happened?"** through reports and dashboards. Data Science extends this by answering **"Why did it happen?", "What will happen?", and "What should we do?"** using statistical analysis and machine learning.

# Question 13

# Question 19

Which of the following best illustrates the relationship between Artificial Intelligence, Machine Learning, and Deep Learning?

## Options

* Deep Learning contains Artificial Intelligence.
* Artificial Intelligence is a subset of Deep Learning.
* Deep Learning is a subset of Machine Learning, which is a subset of Artificial Intelligence.
* Machine Learning and Artificial Intelligence are unrelated fields.

## Answer

✅ **Deep Learning is a subset of Machine Learning, which is a subset of Artificial Intelligence.**

> [!NOTE]
> **Reason**
>
> The hierarchy is:
>
> * **Artificial Intelligence (AI)** is the broadest field.
> * **Machine Learning (ML)** is a subset of AI that enables systems to learn from data.
> * **Deep Learning (DL)** is a specialized subset of ML that uses multi-layer neural networks.
