# Practice Quiz

# Question 1

Which phase of the Data Science lifecycle focuses on understanding the business problem before analyzing the data?

## Options

* Model Deployment
* Business Understanding
* Data Visualization
* Feature Engineering

## Answer

✅ **Business Understanding**

> [!NOTE]
> **Reason**
>
> Every Data Science project begins with **Business Understanding**. This phase defines the business objective, identifies success criteria, and ensures the project solves a meaningful real-world problem before any technical work begins.

# Question 2

Which of the following is considered structured data?

## Options

* Tweets from Twitter
* Images collected from cameras
* A customer table stored in a relational database
* Audio recordings

## Answer

✅ **A customer table stored in a relational database**

> [!NOTE]
> **Reason**
>
> **Structured data** follows a predefined schema consisting of rows and columns, making it easy to store and query using relational databases. Images, audio, and social media posts are examples of unstructured data.

# Question 3

Which programming language is most commonly used for Data Science due to its extensive ecosystem of libraries?

## Options

* HTML
* Python
* CSS
* SQL

## Answer

✅ **Python**

> [!NOTE]
> **Reason**
>
> Python is the most widely used Data Science language because of libraries such as **NumPy**, **Pandas**, **Scikit-learn**, **Matplotlib**, **TensorFlow**, and **PyTorch**, which support data analysis, visualization, and machine learning.

# Question 4

Which stage of the KDD process prepares raw data for analysis by correcting errors and inconsistencies?

## Options

* Model Evaluation
* Data Cleaning and Preprocessing
* Knowledge Presentation
* Deployment

## Answer

✅ **Data Cleaning and Preprocessing**

> [!NOTE]
> **Reason**
>
> Data cleaning removes missing values, duplicates, inconsistencies, and noise to improve data quality. Since machine learning models depend on high-quality data, preprocessing is one of the most important stages of the KDD process.

# Question 5

Which of the following best describes Machine Learning?

## Options

* A method of manually writing rules for every possible situation.
* A technique that enables computers to learn patterns from data without being explicitly programmed.
* A database management system.
* A programming language for web development.

## Answer

✅ **A technique that enables computers to learn patterns from data without being explicitly programmed.**

> [!NOTE]
> **Reason**
>
> Machine Learning enables algorithms to learn relationships from historical data and make predictions or decisions without requiring manually programmed rules for every scenario.

# Question 6

Which of the following is an example of supervised learning?

## Options

* Customer segmentation
* Market basket analysis
* House price prediction
* Topic modeling

## Answer

✅ **House price prediction**

> [!NOTE]
> **Reason**
>
> **Supervised learning** uses labeled data where the target variable is known. Predicting house prices from historical housing data is a classic supervised learning problem because the model learns from known price labels.

# Question 7

What is the primary purpose of data visualization in Data Science?

## Options

* To replace statistical analysis
* To increase database storage capacity
* To communicate insights and identify patterns
* To eliminate missing values automatically

## Answer

✅ **To communicate insights and identify patterns**

> [!NOTE]
> **Reason**
>
> Data visualization helps analysts explore datasets, detect trends, identify anomalies, and communicate findings effectively to technical and non-technical audiences.

# Question 8

Which of the following is an example of unstructured data?

## Options

* Employee salary table
* Sales transaction database
* Customer reviews written in natural language
* Excel spreadsheet containing monthly revenue

## Answer

✅ **Customer reviews written in natural language**

> [!NOTE]
> **Reason**
>
> Customer reviews consist of free-form text without a predefined schema, making them **unstructured data**. Natural Language Processing (NLP) techniques are commonly used to analyze such data.

# Question 9

Why is domain knowledge important in Data Science?

## Options

* It replaces statistical methods.
* It helps interpret results and create meaningful solutions.
* It eliminates the need for machine learning.
* It automatically improves model accuracy.

## Answer

✅ **It helps interpret results and create meaningful solutions.**

> [!NOTE]
> **Reason**
>
> Domain knowledge provides the business context needed to ask the right questions, engineer useful features, interpret model outputs correctly, and ensure that solutions are practical and valuable.

# Question 10

Which of the following best describes Big Data?

## Options

* A dataset that fits easily into spreadsheet software.
* Data that can only be analyzed using SQL.
* Extremely large and complex datasets that require specialized tools and technologies.
* Any dataset containing more than one thousand records.

## Answer

✅ **Extremely large and complex datasets that require specialized tools and technologies.**

> [!NOTE]
> **Reason**
>
> **Big Data** refers to datasets characterized by high **Volume, Velocity, Variety, Veracity, and Value**. Traditional data processing tools are often insufficient, requiring distributed computing frameworks such as Hadoop and Spark.
