# 5.3 Step-by-Step Example

Suppose:

|Attribute Values|
|---|
|915|
|-986|
|50|
|60|

Maximum absolute value:

$$
986
$$

Since 986 has:

$$
3 \text{ digits}
$$

we choose:

$$
j=3
$$

Now normalize:

915/10^3 = 0.915

and:

-986/10^3 = -0.986

All values are scaled downward by shifting decimal positions.
