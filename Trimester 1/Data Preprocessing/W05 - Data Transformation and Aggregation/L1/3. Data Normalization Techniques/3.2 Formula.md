# 3.2 Formula

The transformation formula is:

$$v' = \frac{v-min_A}{max_A-min_A}(new_max_A-new_min_A)+new_min_A$$

where:

|Symbol|Meaning|
|---|---|
|$v$|Original value|
|$v'$|Normalized value|
|$min_A$|Minimum attribute value|
|$max_A$|Maximum attribute value|
|$new_min_A$|New lower bound|
|$new_max_A$|New upper bound|
