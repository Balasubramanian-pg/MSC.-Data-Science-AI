# Question 9

**Question:** What is the primary goal of data reduction?

* **Eliminated Options:**

  * *To clean the data by removing all outliers and correcting inconsistencies:* This is data cleaning, not data reduction.
  * *To convert all numerical data into categorical formats:* This is discretization or encoding.
  * *To increase the accuracy of data by adding new, calculated features:* This is feature engineering.

* **Correct Answer:** **To obtain a reduced representation of the dataset that is smaller in volume but maintains its integrity**

> [!IMPORTANT]
> **Explanation:**
>
> Data reduction seeks to produce a smaller representation:
>
> $$
> \text{Reduced Dataset} \approx \text{Original Dataset}
> $$
>
> while preserving the essential information needed for analysis.
>
> Common data reduction techniques include:
>
> * Dimensionality Reduction
> * Data Compression
> * Sampling
> * Aggregation
