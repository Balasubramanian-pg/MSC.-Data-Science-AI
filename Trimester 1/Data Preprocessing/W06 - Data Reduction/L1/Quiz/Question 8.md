# Question 8

**Question:** When is stratified sampling particularly useful?

* **Eliminated Options:**

  * *When the dataset is perfectly uniform and has no distinct subgroups:* Stratification is unnecessary when no meaningful subgroups exist.
  * *When you want to ensure that no object can be selected more than once:* This describes sampling without replacement.
  * *When the goal is to create the smallest possible sample size:* Stratified sampling focuses on representativeness rather than minimizing sample size.

* **Correct Answer:** **When the dataset is skewed and contains important minority classes that need to be represented in the sample**

> [!NOTE]
> **Explanation:**
>
> Stratified sampling divides the population into homogeneous subgroups called strata:
>
> $$
> \text{Population} = \text{Stratum}_1 + \text{Stratum}_2 + \cdots + \text{Stratum}_n
> $$
>
> Samples are then drawn from each stratum to ensure that important minority groups are adequately represented.
