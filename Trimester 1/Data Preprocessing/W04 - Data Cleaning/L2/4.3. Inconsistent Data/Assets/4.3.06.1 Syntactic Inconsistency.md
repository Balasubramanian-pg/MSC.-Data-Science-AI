# 6.1 Syntactic Inconsistency

Syntactic inconsistency occurs when the format or datatype changes unexpectedly.

Example:

|Expected Type|Actual Value|
|---|---|
|Text|12345|

or:

|Expected Format|
|---|
|DD-MM-YYYY|

but received:

|Actual Format|
|---|
|YYYY/MM/DD|

The issue is structural formatting rather than meaning.
