# Answer

✅ **Attribute**

> [!NOTE]
> **Reason**
>
> An **attribute** is a property or characteristic describing an object. In tabular data, attributes are represented as columns.
>
> For example:
>
> * Object: Student
> * Attributes: Name, Age, Major, GPA
>
> Therefore, "Taxable Income" is an attribute.
