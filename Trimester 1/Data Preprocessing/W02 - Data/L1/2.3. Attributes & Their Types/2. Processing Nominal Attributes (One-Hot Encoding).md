# 2. Processing Nominal Attributes (One-Hot Encoding)


**Processing Nominal Attributes (One-Hot Encoding)**

Nominal attributes are categorical variables with no inherent order, such as country, gender, or product category. Since machine learning models cannot process text directly, these categories must be converted into numbers.

One-hot encoding creates a separate binary column for each category. A value of **1** indicates the category is present, while **0** indicates it is absent.

For example:

| Color | Red | Blue | Green |
| ----- | --: | ---: | ----: |
| Red   |   1 |    0 |     0 |
| Blue  |   0 |    1 |     0 |
| Green |   0 |    0 |     1 |

This method avoids introducing artificial order between categories and is suitable for nominal data. However, it can significantly increase the number of features when a variable has many unique categories.
