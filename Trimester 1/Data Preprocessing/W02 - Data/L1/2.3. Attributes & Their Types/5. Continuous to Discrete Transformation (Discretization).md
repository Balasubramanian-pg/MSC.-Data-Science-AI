# 5. Continuous to Discrete Transformation (Discretization)


**Continuous to Discrete Transformation (Discretization)**

Discretization converts continuous numerical variables into a small number of discrete intervals or bins. For example, age can be grouped into categories such as 0 to 18, 19 to 35, 36 to 60, and above 60.

This transformation simplifies the data, reduces the impact of noise and outliers, and can improve the interpretability of some models. Common methods include equal-width binning, equal-frequency binning, and domain-specific thresholds.

Discretization is most useful when the exact numerical value is less important than the range to which it belongs.
