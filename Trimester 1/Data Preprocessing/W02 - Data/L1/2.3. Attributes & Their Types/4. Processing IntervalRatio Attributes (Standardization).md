# 4. Processing Interval/Ratio Attributes (Standardization)


**Processing Interval/Ratio Attributes (Standardization)**

Interval and ratio attributes are numerical variables, such as age, income, height, or salary. Since these features often have different scales, larger values can dominate machine learning models.

Standardization transforms each feature to have a mean of **0** and a standard deviation of **1**. This ensures that all features contribute equally during model training.

It is commonly used with distance-based and gradient-based algorithms such as K-Means, K-Nearest Neighbors, Support Vector Machines, and Logistic Regression. Standardization preserves the distribution of the data while making features comparable across different scales.
