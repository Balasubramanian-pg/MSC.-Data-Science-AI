# 3. Processing Ordinal Attributes (Ordinal Encoding)

Ordinal attributes are categorical variables whose values have a meaningful order or ranking. Examples include education level (High School < Bachelor's < Master's < PhD) and customer satisfaction (Low < Medium < High).

Machine learning models cannot directly interpret text categories, so ordinal values must be converted into numbers. Ordinal encoding assigns an integer to each category while preserving its natural order.

For example:

| Category | Encoded Value |
| -------- | ------------: |
| Low      |             1 |
| Medium   |             2 |
| High     |             3 |

Unlike one-hot encoding, ordinal encoding retains the ranking between categories. It should only be used when the order is meaningful. Applying it to unordered categories, such as colors or countries, introduces false relationships and can reduce model performance.
