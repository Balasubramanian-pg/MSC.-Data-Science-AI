# 3.0.2. Noise and Measurement Errors

Transitioning from the general concept of data quality to specific issues, we first examine noise. Noise refers to the random variance or error in measured values. It is the distortion of the true signal caused by imperfect measurement instruments, environmental interference, or human error.

### 3.0.2.1. The Mathematical Nature of Noise

Mathematically, an observed value $$x$$ can be decomposed into the true signal $$s$$ and the noise $$\epsilon$$:

$$
x = s + \epsilon
$$

where:
- $$x$$ = observed value
- $$s$$ = true underlying signal
- $$\epsilon$$ = random noise component

To emphasize the decomposition of an observed value, we restate the formula:

$$
x = s + \epsilon
$$

Noise typically has a mean of zero, meaning it does not systematically bias the results, but it increases the variance of the data. This increased variance reduces the statistical power of hypothesis tests and makes it harder for machine learning models to learn the true underlying patterns.

>[!Note]
> Noise is random and unsystematic. While it obscures the true signal, it does not pull the average estimate in a specific direction.
