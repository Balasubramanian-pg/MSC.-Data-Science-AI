# 1. Creating Numerical Data with `linspace`

The lecture revisits:

```python
np.linspace()
```

General structure:

```python
np.linspace(start, stop, number_of_points)
```

Example:

```python
x = np.linspace(0, 10, 100)
```

Meaning:

- start at 0
    
- stop at 10
    
- create 100 evenly spaced values
