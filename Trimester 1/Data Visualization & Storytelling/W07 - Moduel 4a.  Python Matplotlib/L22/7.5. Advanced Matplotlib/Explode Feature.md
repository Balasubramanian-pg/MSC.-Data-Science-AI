# Explode Feature

Transcript reference:

```python
explode = [0, 0, 0, 0.1, 0]

plt.pie(
    traffic,
    labels=sources,
    explode=explode,
    autopct='%1.1f%%'
)
```

This creates visual emphasis.

But overuse becomes manipulative.

Many executive dashboards misuse explode effects to artificially exaggerate categories.
