# RGBA Color System

The transcript discusses RGBA tuples.

RGBA stands for:

|Component|Meaning|
|---|---|
|R|Red|
|G|Green|
|B|Blue|
|A|Alpha transparency|

Values range:

$$
0 \to 1
$$

Example:

```python
color=(0.2, 0.4, 0.8, 0.5)
```

This means:

- low red
    
- moderate green
    
- strong blue
    
- 50% transparency
