# Why Colormaps Exist

A colormap maps numerical values to colors.

Instead of assigning one static color:

```python
blue
```

a colormap creates:

$$
f(x) \to \text{color}
$$

This enables:

- heatmaps
    
- density maps
    
- correlation intensity
    
- elevation maps
    
- probability gradients
