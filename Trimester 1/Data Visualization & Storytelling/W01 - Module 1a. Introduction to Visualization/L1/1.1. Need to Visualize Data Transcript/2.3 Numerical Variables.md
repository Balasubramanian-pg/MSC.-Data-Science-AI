# 2.3 Numerical Variables

### Continuous Numerical Variables

Values can take any number within a range.

#### Examples

- Revenue
    
- Temperature
    
- Voter turnout percentage
    

### Discrete Numerical Variables

Countable integers.

#### Examples

- Number of customers
    
- Number of votes
    
- Number of states
    

### Suitable Charts

- Histogram
    
- Scatter plot
    
- Line chart
    
- Box plot
