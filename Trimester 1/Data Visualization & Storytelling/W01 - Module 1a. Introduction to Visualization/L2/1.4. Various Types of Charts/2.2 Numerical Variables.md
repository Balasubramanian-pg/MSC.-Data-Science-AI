# 2.2 Numerical Variables

### Continuous Variables

Can take any value within a range.

#### Examples

- Weight of cars
    
- Height of people
    
- Voter turnout ratio
    

### Discrete Variables

Countable integers.

#### Examples

- Number of tweets
    
- Number of complaints
    
- Number of words
    

### Suitable Charts

- Histogram
    
- Scatter plot
    
- Bubble chart
