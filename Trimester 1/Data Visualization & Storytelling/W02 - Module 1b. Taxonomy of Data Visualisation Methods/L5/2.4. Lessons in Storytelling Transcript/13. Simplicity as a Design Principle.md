# 13. Simplicity as a Design Principle

One of the strongest lessons in visualization is:

> Simplicity increases comprehension.

Many charts become ineffective because they contain unnecessary elements.

### Examples of Unnecessary Complexity

* 3D effects
* Excessive gridlines
* Decorative graphics
* Redundant labels
* Unnecessary color schemes

### Better Approach

Include only elements that support the story.

Ask:

> Does this help communicate the insight?

If not, remove it.
