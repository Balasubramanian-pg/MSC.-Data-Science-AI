# 12. Pre-Attentive Attributes

Pre-attentive attributes are visual properties processed almost instantly.

Examples include:

* Color
* Size
* Shape
* Orientation
* Position

### Example

Imagine a table of 100 numbers.

If one number is red:

```text
12 14 15 11 18

13 15 16 22 14

17 19 42 16 12
       ↑
```

The red value is noticed immediately.

No conscious searching is required.

### Applications

Use pre-attentive attributes to:

* Highlight outliers
* Identify risks
* Emphasize targets
* Focus attention
