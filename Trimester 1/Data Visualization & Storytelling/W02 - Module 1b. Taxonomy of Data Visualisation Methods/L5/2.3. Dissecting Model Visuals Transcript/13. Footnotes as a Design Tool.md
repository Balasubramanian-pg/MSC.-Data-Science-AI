# 13. Footnotes as a Design Tool

Many visualizations fail because they attempt to show everything simultaneously.

Instead:

### Main Visual

Should contain:

* Key message
* Primary insight
* Important comparisons

### Footnotes

Should contain:

* Methodology
* Definitions
* Sample sizes
* Assumptions
* Supporting details

### Benefit

Separates:

```text
Need to Know
```

from

```text
Nice to Know
```
