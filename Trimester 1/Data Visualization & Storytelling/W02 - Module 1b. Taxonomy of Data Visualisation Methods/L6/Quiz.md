## Question 1

**Correct Answer: To show the range of quantitative values for different categories.**

Eliminate the wrong answers:

* **To show the flow of data between different stages.** ❌ This is the purpose of a Sankey diagram.
* **To compare the constituent parts of a whole.** ❌ This describes composition charts such as stacked bars or pie charts.
* **To display hierarchical data in a circular format.** ❌ This describes charts like sunburst diagrams.

**Remaining correct option:**

* **To show the range of quantitative values for different categories.** ✅

## Question 2

**Correct Answer: Sankey diagram**

Eliminate the wrong answers:

* **Gantt Chart** ❌ Used for scheduling and displaying task durations over time.
* **Bubble Hierarchy** ❌ Used to visualize hierarchical relationships, not flow.
* **Small Multiples** ❌ Used to compare multiple similar charts side by side.

**Remaining correct option:**

* **Sankey diagram** ✅
