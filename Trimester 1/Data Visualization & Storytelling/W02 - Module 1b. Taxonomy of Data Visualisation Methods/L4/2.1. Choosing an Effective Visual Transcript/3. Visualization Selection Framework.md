# 3. Visualization Selection Framework

The first question should always be:

> What am I trying to communicate?

```mermaid
flowchart TD

A[Start]
--> B{Objective?}

B --> C[Single Number]
B --> D[Exact Values]
B --> E[Relationship]
B --> F[Trend]
B --> G[Comparison]
B --> H[Composition]
B --> I[Cumulative Change]
````

The objective determines the visual.
