# Core Idea

Normal Pandas handles:

|Type|Example|
|---|---|
|numbers|sales|
|strings|city names|
|dates|timestamps|

GeoPandas adds:

```text
geometry
```

Meaning:

- points
    
- lines
    
- polygons
    
- regions
    
- spatial boundaries
    

The transcript explains:

> “The geometry column is what brings in the richness to the map visualisations.”

That single sentence is the heart of geospatial analytics.
