# Example of Poor Design

Imagine:

- 12 pie charts
    
- 15 colors
    
- scrolling dashboard
    
- tiny labels
    
- multiple filters
    
- inconsistent formatting
    

The audience must constantly remember:

- what colors mean
    
- previous chart values
    
- legend mappings
    
- filter state
    
- metric definitions
    

This exhausts working memory.
