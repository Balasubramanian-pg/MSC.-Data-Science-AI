# Why This Matters in Dashboards

Most poor dashboards overload short-term memory.

Examples:

- too many KPIs
    
- too many filters
    
- dense tables
    
- excessive colors
    
- complicated legends
    
- scattered layouts
    

Users are forced to remember:

- category mappings
    
- previous chart values
    
- legend meanings
    
- filter conditions
    
- metric definitions
    

This creates cognitive overload.
