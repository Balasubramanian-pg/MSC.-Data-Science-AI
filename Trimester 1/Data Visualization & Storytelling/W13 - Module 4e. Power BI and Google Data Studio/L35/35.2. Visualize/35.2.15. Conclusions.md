# 35.2.15. Conclusions

An optimized dashboard moves an organization from static, descriptive reporting to active, exploratory data analysis. This transition is achieved by combining multiple visual layers with correct weighted calculations.

### 15.1. Anatomy of a Weighted Calculation
The foundation of any analytical dashboard is the calculated field:

$$
\text{Weighted KPI} = \frac{\sum \text{Numerator}}{\sum \text{Denominator}}
$$

- **Numerator:** The aggregated target metric (e.g., total profit, total cost).
- **Denominator:** The aggregated base metric (e.g., total sales, total transaction volume).

### 15.2. Comparing Visual Component Strengths
The following table compares the strengths, dimensions, and optimal use cases of the key visual components used in business intelligence.

| Visualization Type | Primary Dimension | Primary Metric | Optimal Business Use Case |
|----------|:----------:|:----------:|----------:|
| **Doughnut Chart** | Single Categorical Attribute | Sales Volume | Part-to-whole share analysis |
| **Geographical Map** | Spatial / Administrative | Weighted Profit Percentage | Location-based margin performance |
| **Tree Map** | Nested Multi-Level Hierarchy | Sales Volume | Hierarchical category volume analysis |
| **Waterfall Chart** | Categorical Segment | Cumulative Profit | Sequential contribution and leak identification |

Using these components under strict layout rules ensures that aggregate data is both statistically accurate and easy to interpret for decision-makers.
