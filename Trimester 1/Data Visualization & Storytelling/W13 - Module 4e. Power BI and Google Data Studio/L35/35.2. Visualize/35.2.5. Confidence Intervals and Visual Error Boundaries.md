# 35.2.5. Confidence Intervals and Visual Error Boundaries

A visual dashboard translates mathematical uncertainty into intuitive boundaries. In dashboarding, the margin of error is not always expressed as a confidence band; instead, it is represented visually by styling choices, including borders, shadows, and color gradients.

The visual margin of error increases when:
- Segment transaction volume decreases.
- Transaction-to-transaction variability increases.
- The dashboard filter is set to an extremely granular, low-volume level.

This creates a fundamental design tradeoff:

The following table summarizes the tradeoff between visual detail and statistical precision.

| Dashboard Focus | Statistical Effect | Visual Effect |
|----------|:----------:|----------:|
| Broad Aggregations | Low standard error | Smooth, stable trends |
| Granular Slicing | High standard error | Noisy, volatile trends |
| Dynamic Filtering | Variable sample size | Interactive variability |
