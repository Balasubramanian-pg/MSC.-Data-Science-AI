# 35.2.7. Tree Maps with Drill-Down Functionality

Geographical trends must be analyzed in tandem with product performance, which requires a visualization capable of handling deeply nested categorical hierarchies. A tree map displays hierarchical data as a set of nested rectangles, where the area of each rectangle represents its metric size (such as sales volume) and the color can represent another metric (such as profit margin).

In our sales dashboard, the tree map is structured with two levels of dimensions:
- **Category** (e.g., Technology, Furniture, Office Supplies)
- **Subcategory** (e.g., Phones, Chairs, Paper)

To navigate this complex structure without cluttering the screen, we enable the **drill-down** feature. When drill-down is enabled:
- Users see the top-level categories first.
- Clicking on a category like Furniture drills down to show only its subcategories (Chairs, Tables, Bookcases).

This hierarchy allows the dashboard to maintain a clean layout while preserving deep analytical pathways.
