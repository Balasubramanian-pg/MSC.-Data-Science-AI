# 35.2.11. Sharing and Deployment Options

Once a dashboard is fully constructed and styled, it must be deployed to the target audience. Business intelligence tools offer multiple distribution pathways:
- **PDF Export:** Allows users to download a static, offline snapshot of the current dashboard state, ideal for periodic executive summaries or physical printouts.
- **Interactive Cloud Sharing:** Provides users with a direct web link or access permissions to interact with the live dashboard in their browser without requiring local software or licenses.
- **Native Database Connectors:** Dashboards can be linked directly to production databases (such as SQL Server). This connection enables scheduled daily refreshes, ensuring that the dashboard automatically displays up-to-date transaction records without manual intervention.
