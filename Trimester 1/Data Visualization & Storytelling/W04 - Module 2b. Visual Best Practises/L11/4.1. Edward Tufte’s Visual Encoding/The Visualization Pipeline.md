# The Visualization Pipeline

```mermaid
flowchart LR
    A[Raw Data]
    --> B[Visual Encoding]
    --> C[Human Perception]
    --> D[Interpretation]
    --> E[Insight]
    --> F[Decision]
```

Every stage can fail.

Most failures occur because:

- wrong encoding is chosen
    
- perception becomes inefficient
    
- cognitive load increases
    
- comparisons become difficult
