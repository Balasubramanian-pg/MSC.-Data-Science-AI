# NLP Complexity Hierarchy

```mermaid
flowchart TD
    A[Raw Text]
    
    A --> B[Word Frequency]
    B --> C[Co-occurrence]
    C --> D[Semantic Similarity]
    D --> E[Word Embeddings]
    E --> F[Topic Modeling]
    F --> G[Latent Semantic Structure]
```

This transition is massive.

Traditional text analytics asks:

```text
What words occur?
```

Modern NLP asks:

```text
What meanings are encoded in linguistic context?
```
