# Visualization Techniques

Common outlier visuals:

- scatter plots
    
- box plots
    
- z-score charts
    
- anomaly heatmaps
    

Outlier detection often depends on standardization.

Example z-score formula:

Where:

- (x) = observed value
    
- (\mu) = mean
    
- (\sigma) = standard deviation
    

Large absolute z-scores suggest anomaly.
