# Core Idea

Normally, plots use continuous numerical axes:

- x = 1, 2, 3, 4
    
- y = numeric values
    

But bar charts often use categories:

- Apple
    
- Mango
    
- Banana
    

These are labels, not numbers.

So Bokeh must be explicitly told:

> "Treat the x-axis as categories, not numeric values."
