# 4.2.5. Example of SVD Truncation

Suppose:
- original data matrix is denoted by $$X$$
- number of observations $$m = 100$$
- number of features $$n = 50$$
- desired target latent dimensions $$k = 5$$

### Step 1: Define Original Dimensions
$$
X_{100 \times 50}
$$

### Step 2: Formulate Full Decomposition Matrices
$$
U_{100 \times 100}, \Sigma_{100 \times 50}, V^T_{50 \times 50}
$$

### Step 3: Identify Target Top Components
$$
k = 5
$$

### Step 4: Truncate the Orthogonal Matrices
$$
U_{100 \times 5}, \Sigma_{5 \times 5}, V^T_{5 \times 50}
$$

### Step 5: Compute the Reduced Feature Space
**$$X_{reduced} = U_{100 \times 5} \Sigma_{5 \times 5}$$**
