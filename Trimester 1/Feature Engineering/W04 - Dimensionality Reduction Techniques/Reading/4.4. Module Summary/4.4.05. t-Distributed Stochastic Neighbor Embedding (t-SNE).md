# 4.4.5. t-Distributed Stochastic Neighbor Embedding (t-SNE)

While PCA and SVD excel at linear projection, they fail to map complex, non-linear manifolds. t-Distributed Stochastic Neighbor Embedding abandons linear combinations entirely to focus on preserving local spatial structures.

The algorithm minimizes the discrepancy between high-dimensional and low-dimensional probability distributions using Kullback-Leibler Divergence:

$$
KL(P || Q) = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}
$$

where:

- $$P$$ = the high-dimensional probability distribution matrix
- $$Q$$ = the low-dimensional probability distribution matrix
- $$p_{ij}$$ = the original structural affinities between points
- $$q_{ij}$$ = the projected mapping affinities

This objective function forces points that are clustered in high-dimensional space to remain strictly adjacent in the resulting two-dimensional or three-dimensional visual output.
