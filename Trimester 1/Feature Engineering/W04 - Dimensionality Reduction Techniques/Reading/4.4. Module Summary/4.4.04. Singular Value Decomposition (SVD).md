# 4.4.4. Singular Value Decomposition (SVD)

Singular Value Decomposition serves as the fundamental engine behind many advanced dimensionality reduction algorithms. Instead of relying on a covariance matrix, it applies direct matrix factorization to extract latent structures.

The canonical decomposition isolates structural components via the equation:

$$
X = U \Sigma V^T
$$

where:

- $$X$$ = the original data matrix
- $$U$$ = the orthogonal matrix of left singular vectors (data point relationships)
- $$\Sigma$$ = the diagonal matrix of singular values (component importance)
- $$V^T$$ = the orthogonal matrix of right singular vectors (feature relationships)

SVD is particularly critical for sparse data matrices, such as term-frequency matrices in natural language processing, because it mathematically bypasses the need for mean-centering the variables prior to factorization.
