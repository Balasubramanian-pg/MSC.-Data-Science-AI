# 4.4.7. Example of Information Retention in Dimensionality Reduction

When executing data compression, we must quantitatively monitor the "explained variance ratio" to ensure the actual statistical signal is not discarded.

Suppose:
- Original high-dimensional matrix possesses 200 features
- Total combined variance of the original dataset = 850.0
- Variance captured by the first extracted component = 510.0
- Variance captured by the second extracted component = 212.5
- Target variance retention threshold = 85%

### Step 1: Identify Total System Variance

$$
\text{Total Variance} = 850.0
$$

### Step 2: Compute Proportion for Component One

$$
P_1 = \frac{510.0}{850.0} = 0.60
$$

### Step 3: Compute Proportion for Component Two

$$
P_2 = \frac{212.5}{850.0} = 0.25
$$

### Step 4: Compute Cumulative Explained Variance

$$
\text{Cumulative Proportion} = 0.60 + 0.25 = 0.85
$$

### Step 5: Evaluate Against Threshold

$$
\text{Total Retained} = 85\%
$$

**Final Decision:** By utilizing only two newly engineered components, the algorithm perfectly met the 85% variance retention threshold while discarding 198 dimensions.
