# 4.3.1. The Limitation of Linear Projections

Techniques like Principal Component Analysis strictly preserve global variance by creating linear combinations of features. However, real-world data often exists on complex, non-linear manifolds. 

When high-dimensional data is inherently non-linear, linear dimensionality reduction forces structurally distant points to overlap in the projected space. To effectively visualize non-linear topologies, we require an algorithm that prioritizes local structure over global variance. t-Distributed Stochastic Neighbor Embedding (t-SNE) is specifically optimized to fulfill this visualization objective.
