# 4.3.6. Example of a t-SNE Optimization Workflow

Suppose:
- Original high-dimensional feature set contains handwritten digits.
- Number of observations is 1000.
- Original dimensionality is 784.
- Desired low dimensionality is 2.
- The hyperparameter Perplexity (number of nearest neighbors to balance) is set to 30.

### Step 1: Pre-process via Principal Component Analysis
Reduce the original 784 dimensions to 50 dimensions to aggressively cut computational complexity from the distance calculations.

### Step 2: Compute High-Dimensional Affinities
Calculate all symmetric probabilities for the 50-dimensional space using:

$$
p_{ij} = \frac{p_{j|i} + p_{i|j}}{2000}
$$

### Step 3: Initialize Low-Dimensional Coordinates
Randomly assign initial 2D coordinates for all 1000 observations using a standard normal distribution.

### Step 4: Compute Low-Dimensional Affinities
Calculate probabilities in the 2D space utilizing the heavy-tailed t-distribution equation:

$$
q_{ij} = \frac{\left(1 + \|y_i - y_j\|^2\right)^{-1}}{\sum_{k \neq l} \left(1 + \|y_k - y_l\|^2\right)^{-1}}
$$

### Step 5: Execute Gradient Descent
Iteratively shift the 2D coordinates to minimize the Kullback-Leibler divergence until the mapped clusters visually separate.
