# 4.3.7. Strategic Usage: Visualization vs. Feature Engineering

It is mathematically critical to distinguish t-SNE from classical feature extraction methodologies.

t-SNE is strictly designed for exploratory data visualization. It assists practitioners in rapidly identifying hidden clusters, confirming grouping similarities, and isolating potential anomalies.

However, t-SNE is profoundly unsuited for feature engineering in predictive modeling. The cost function optimization relies heavily on a stochastic initialization. Consequently, executing the algorithm multiple times on the exact same dataset will generate radically different coordinate mappings. Because there is no generalized algebraic projection matrix, the transformation cannot be mapped to unseen out-of-sample data.
