# 4.3.9. Common Misinterpretations

Because the resulting visual clusters are often aesthetically pleasing, practitioners frequently draw mathematically invalid conclusions from t-SNE output plots.

### 9.1 Interpretation 1

>[!Warning]
> "The physical distance between two distinct clusters in a t-SNE plot represents their actual distance in the original feature space."

Wrong.
t-SNE preserves local neighborhoods, not global geometry. The space between completely separate clusters is warped by the algorithm and holds almost no meaningful absolute distance metric.

### 9.2 Interpretation 2

>[!Warning]
> "The physical size or density of a t-SNE cluster reflects the variance of that group in the original data."

Wrong.
The algorithm actively adapts to the regional density of the data, mathematically expanding dense clusters and compressing sparse ones. Visual density in the plot is heavily distorted.

### 9.3 Interpretation 3

>[!Warning]
> "I can use the 2D t-SNE output as input features to train my random forest classifier."

Wrong.
Because t-SNE is a stochastic mapping without a persistent transformation matrix, it is impossible to transform future testing data into the exact same spatial coordinates. It must never be used in a predictive pipeline.
