# 4.3.2. The Probabilistic Framework for Local Structure

t-SNE Abandons variance maximization. Instead, it operates through a probabilistic framework designed to capture pairwise neighborhood relationships.

The core intuition is that Euclidean distances in a high-dimensional space can be seamlessly converted into conditional probabilities representing similarities. If two data points are physically close in the original feature space, the probability that they are neighbors is mathematically high.
