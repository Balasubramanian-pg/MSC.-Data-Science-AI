# 4.3.8. Comparing t-SNE and PCA

The following table explicitly details the structural and strategic differences between these two prominent dimensionality reduction algorithms.

| Feature | Principal Component Analysis | t-SNE |
|---|:---:|---:|
| **Mathematical Objective** | Preserve global variance | Preserve local neighborhoods |
| **Mapping Geometry** | Strictly linear combinations | Highly complex non-linear |
| **Output Stability** | Completely deterministic | Highly stochastic |
| **Predictive Utility** | Serves as robust model input | None (Cannot transform new data) |
