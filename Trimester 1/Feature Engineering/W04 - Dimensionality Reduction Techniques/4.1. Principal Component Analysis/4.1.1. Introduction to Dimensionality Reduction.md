# 4.1.1. Introduction to Dimensionality Reduction

High-dimensional datasets frequently suffer from the curse of dimensionality, where excessive features obscure meaningful patterns and cause statistical models to overfit. 

Principal Component Analysis (PCA) is an unsupervised dimensionality reduction technique that transforms a high-dimensional dataset into a lower-dimensional subspace while retaining the maximum possible variance. It achieves this structural transformation by creating entirely new, uncorrelated features called **Principal Components (PCs)**. These components serve as optimized summaries of the original data.
