# 4.1.10. Common Misinterpretations

PCA is ubiquitous in exploratory data analysis but is frequently misunderstood by practitioners.

### 10.1 Interpretation 1

>[!Warning]
> "PCA automatically selects the most important features."

Wrong. 
PCA does not perform feature selection. It creates entirely new composite features via linear combinations. The original variables are mathematically blended, not distinctly selected or discarded.

### 10.2 Interpretation 2

>[!Warning]
> "PCA works well for identifying any underlying data structure."

Wrong. 
PCA strictly assumes relationships in the data are linear. If the true data structure forms an inherently non-linear manifold (such as a geometric spiral), PCA will completely fail to capture the underlying topology.

### 10.3 Interpretation 3

>[!Warning]
> "Standardization is optional before performing PCA."

Wrong. 
Because the algorithm maximizes variance, unscaled features with naturally massive numerical ranges will completely dominate the principal components, destroying the true statistical relationships.
