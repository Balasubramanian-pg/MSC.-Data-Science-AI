# 4.1.2. The Theoretical Framework of PCA

PCA operates by systematically identifying the mathematical directions of maximum variance within the dataset.

The foundation of this transformation is the covariance matrix. The covariance matrix captures how all pairs of original features vary together, allowing the algorithm to identify redundant, highly correlated variables that can be mathematically collapsed into single dimensions.
