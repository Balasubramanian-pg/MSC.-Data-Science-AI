# 7.1. Time Series Feature Engineering Concepts

## 7.1.1. From Static Data to Temporal Data

Statistical modeling assumes that observations carry information.

In traditional tabular data, each row is independent. We model relationships like:

$$
Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \epsilon_i
$$

where:

- $$Y_i$$= response variable for observation$$i$$

- $$X_{1i}, X_{2i}$$ = predictor variables

- $$\epsilon_i$$ = independent error term

- $$i = 1, 2, \dots, n$$

This independence assumption collapses in time series data. Each observation $$Y_t$$is indexed by time$$t$$, and the value at time $$t$$ depends on values at earlier times. The fundamental difference is temporal dependency.

>[!Note]
> In time series, the order of observations is itself information. Shuffling the data destroys the signal.

## 7.1.2. Why Static Feature Engineering Is Fundamentally Incomplete

Suppose two analysts model the same stock price series.

- Analyst A treats each day's closing price as an independent observation and fits a standard regression

- Analyst B incorporates yesterday's price as a predictor

Analyst B's model will almost certainly outperform Analyst A's.

This happens because of **autocorrelation**: correlation between a variable and its own lagged values. The key insight is:

>[!Note]
> A time series observation is not a random draw from a population. It is a realization of a stochastic process evolving through time.

That means the sample at time $$t$$ has its own probability structure conditional on history. The past directly influences the present.

## 7.1.3. Core Characteristics of Time Series Data

### 3.1 Temporal Dependency (Autocorrelation)

Future values depend on past observations. Formally, the autocorrelation at lag $$k$$ is:

$$
\rho_k = \frac{\text{Cov}(Y_t, Y_{t-k})}{\sigma_{Y_t} \sigma_{Y_{t-k}}}
$$

where:

- $$\rho_k$$= autocorrelation coefficient at lag$$k$$

- $$Y_t$$= value at time$$t$$

- $$Y_{t-k}$$= value at time$$t-k$$

- $$\sigma_{Y_t}$$ = standard deviation of the series

Positive autocorrelation means high values tend to follow high values; negative autocorrelation means high values tend to follow low values.

### 3.2 Trend and Seasonality

**Trend** is a long-term directional movement in the series. Mathematically:

$$
T_t = f(t)
$$

where $$f(t)$$ is a slowly changing function of time (often linear or polynomial).

**Seasonality** is a recurring pattern at fixed intervals. For monthly data with annual seasonality:

$$
S_t = S_{t+12}
$$

where the seasonal component repeats every 12 periods.

### 3.3 Stationarity vs. Non-Stationarity

A stationary time series has statistical properties that do not change over time:

$$
E(Y_t) = \mu \quad \text{(constant mean)}
$$

$$
\text{Var}(Y_t) = \sigma^2 \quad \text{(constant variance)}
$$

$$
\text{Cov}(Y_t, Y_{t-k}) = \gamma_k \quad \text{(covariance depends only on lag } k\text{)}
$$

Non-stationary series violate one or more of these conditions. Most forecasting models assume stationarity; non-stationary data must be transformed (differencing, detrending) before modeling.

### 3.4 Temporal Order

The requirement to maintain sequence is absolute. Shuffling time-ordered data destroys the underlying dependency structure and produces misleading results.

>[!Warning]
> Never shuffle time series data before splitting into train and test sets. Temporal order must be preserved to prevent data leakage from the future into the past.

## 7.1.4. Time-Based (Calendar) Features

Calendar features extract interpretable components from datetime indices.

### 4.1 Datetime Components

From a timestamp $$t$$, we can extract:

| Component | Description | Example |
|---|---|---|
| Day of month | Calendar day (1-31) | 15 |
| Weekday | Day of week (0-6) | 2 (Tuesday) |
| Month | Calendar month (1-12) | 6 (June) |
| ISO week number | Week of year (1-52) | 24 |

These components capture cyclical behavior. For example, retail sales often spike on weekends regardless of other factors.

### 4.2 Binary Indicators

Binary flags encode domain knowledge efficiently:

$$
\mathbb{I}_{\text{weekend}} = \begin{cases} 1 & \text{if weekday} \in \{5, 6\} \\ 0 & \text{otherwise} \end{cases}
$$

where:

- $$\mathbb{I}_{\text{weekend}}$$ = indicator variable for weekend

- weekday 5 = Saturday

- weekday 6 = Sunday

This single binary feature can capture weekly cyclicality that would otherwise require multiple dummy variables.

## 7.1.5. Lag Features

Lag features create memory by shifting the target or predictor variables backward in time.

### 5.1 Construction of Lag Features

For a series $$Y_t$$, the lag-$$k$$ feature is:

$$
Y_{t-k}^{\text{(lag)}} = Y_{t-k}
$$

Common lag choices include:

| Lag | Rationale | Use Case |
|---|---|---|
| $$t-1$$ | Immediate past | Short-term dependency |
| $$t-3$$ | Recent history | Medium-term smoothing |
| $$t-7$$ | Same day last week | Weekly seasonality |

### 5.2 Handling Missing Values

Shifting creates initial NaN values because there is no data before the series begins. For lag-$$k$$, the first $$k$$ observations become missing:

$$
Y_1^{\text{(lag-3)}} = \text{NaN}, \quad Y_2^{\text{(lag-3)}} = \text{NaN}, \quad Y_3^{\text{(lag-3)}} = \text{NaN}
$$

These must be handled through:

- dropping the incomplete rows

- forward-filling with available values

- imputing with the series mean or median

>[!Tip]
> The number of lag features to create depends on the autocorrelation structure. Examine the autocorrelation function (ACF) plot to identify which lags carry significant signal.

## 7.1.6. Rolling Statistics

Rolling statistics summarize local behavior within a moving window.

### 6.1 Rolling Mean

The rolling mean at time $$t$$with window size$$w$$ is:

$$
\bar{Y}_t^{(w)} = \frac{1}{w} \sum_{i=0}^{w-1} Y_{t-i}
$$

where:

- $$w$$ = window size (number of periods)

- $$Y_{t-i}$$= value at time$$t-i$$

The rolling mean smooths noise to reveal underlying local trends. Larger $$w$$ produces smoother series but lags more behind sudden changes.

### 6.2 Rolling Standard Deviation

The rolling standard deviation quantifies local volatility:

$$
\sigma_t^{(w)} = \sqrt{\frac{1}{w-1} \sum_{i=0}^{w-1} \left(Y_{t-i} - \bar{Y}_t^{(w)}\right)^2}
$$

where:

- $$\sigma_t^{(w)}$ = rolling standard deviation at time $$t$$

- $$\bar{Y}_t^{(w)}$$= rolling mean at time$$t$$

High rolling standard deviation indicates periods of instability; low values indicate stability.

### 6.3 Rolling Trend (Slope) Features

Fitting a linear regression within a moving window captures the local rate of change. For window $$w$$, we estimate:

$$
Y_{t-i} = \beta_{0t} + \beta_{1t}(t-i) + \epsilon_{t-i}, \quad i = 0, 1, \dots, w-1
$$

The slope coefficient $$\beta_{1t}$$ represents the local trend direction at time $$t$$:

- $$\beta_{1t} > 0$$ indicates an upward trend

- $$\beta_{1t} < 0$$ indicates a downward trend

- $$\beta_{1t} \approx 0$$ indicates a flat or stable period

This is more informative than the rolling mean alone because it distinguishes between levels and directions of change.

## 7.1.7. Domain-Specific Feature Engineering

### 7.1 Finance: Market Indicators

Financial time series demand specialized features that encode market dynamics.

#### 7.1.1 Moving Averages

The simple moving average (SMA) over $$w$$ periods smooths price paths:

$$
\text{SMA}_t^{(w)} = \frac{1}{w} \sum_{i=0}^{w-1} P_{t-i}
$$

where $$P_t$$ = price at time $$t$$. Common windows include 14-day, 50-day, and 200-day averages.

#### 7.1.2 Relative Strength Index (RSI)

RSI is a momentum oscillator measuring speed and magnitude of price movements:

$$
\text{RSI} = 100 - \frac{100}{1 + \text{RS}}
$$

where:

$$
\text{RS} = \frac{\text{Average Gain over } w \text{ periods}}{\text{Average Loss over } w \text{ periods}}
$$

Interpretation thresholds:

| RSI Value | Interpretation |
|---|---|
| RSI > 70 | Overbought condition |
| RSI < 30 | Oversold condition |
| 30 ≤ RSI ≤ 70 | Neutral territory |

#### 7.1.3 Bollinger Bands

Bollinger Bands visualize expected price variation using mean $$\pm$$ 2 standard deviations:

$$
\text{Upper Band}_t = \text{SMA}_t^{(w)} + 2\sigma_t^{(w)}
$$

$$
\text{Lower Band}_t = \text{SMA}_t^{(w)} - 2\sigma_t^{(w)}
$$

where:

- $$\text{SMA}_t^{(w)}$$ = moving average at time $$t$$

- $$\sigma_t^{(w)}$$ = rolling standard deviation at time $$t$$

Prices touching or exceeding the bands signal unusual volatility or potential reversal points.

### 7.2 Healthcare: Physiological Signals

Physiological time series require features that capture cardiac and autonomic function.

#### 7.2.1 RR Intervals

The RR interval measures time between consecutive cardiac R-peaks:

$$
\text{RR}_i = t_{R_{i+1}} - t_{R_i}
$$

where:

- $$t_{R_i}$$ = timestamp of the $$i$$-th R-peak

- $$\text{RR}_i$$ = interval between peak $$i$$ and peak $$i+1$$

Heart rate in beats per minute is derived as:

$$
\text{HR}_i = \frac{60,000}{\text{RR}_i \text{ (in milliseconds)}}
$$

#### 7.2.2 Heart Rate Variability (HRV)

HRV quantifies variation in RR intervals, reflecting autonomic nervous system health. Greater HRV typically indicates healthier cardiac regulation.

#### 7.2.3 RMSSD (Root Mean Square of Successive Differences)

RMSSD captures rapid beat-to-beat variations:

$$
\text{RMSSD} = \sqrt{\frac{1}{n-1} \sum_{i=1}^{n-1} (\text{RR}_{i+1} - \text{RR}_i)^2}
$$

where:

- $$n$$ = number of RR intervals

- $$\text{RR}_{i+1} - \text{RR}_i$$ = successive difference

RMSSD is particularly sensitive to parasympathetic (vagal) activity and short-term physiological changes.

#### 7.2.4 Pre/Post-RR Features

Contextual features surrounding an event (e.g., an arrhythmia) provide temporal grounding:

$$
\text{Pre-RR} = \text{RR interval immediately before the event}
$$

$$
\text{Post-RR} = \text{RR interval immediately after the event}
$$

The ratio or difference between pre and post intervals helps classify rhythm abnormalities.

## 7.1.8. Visualization and Model Integration

### 8.1 Visualizing Rolling Statistics

Plotting rolling statistics against the raw series is essential for verification. A well-chosen rolling mean should:

- reduce noise visibly

- preserve major turning points

- not lag excessively behind rapid changes

If the rolling mean oversmooths, reduce $$w$$. If it is too noisy, increase $$w$$.

### 8.2 Model Readiness

After feature engineering, the data must be converted into a 2D array suitable for traditional machine learning:

$$
\mathbf{X} = \begin{bmatrix} x_{1,1} & x_{1,2} & \cdots & x_{1,p} \\ x_{2,1} & x_{2,2} & \cdots & x_{2,p} \\ \vdots & \vdots & \ddots & \vdots \\ x_{n,1} & x_{n,2} & \cdots & x_{n,p} \end{bmatrix}
$$

where:

- $$n$$ = number of samples (time periods)

- $$p$$ = number of engineered features

- $$x_{i,j}$$ = value of feature $$j$$ at time $$i$$

Each row represents one time period; each column represents one engineered feature. This structure is compatible with models like Logistic Regression, Random Forest, and Gradient Boosting.

## 7.1.9. Common Misinterpretations

### Interpretation 1

>[!Warning]
> "Lag features eliminate the need for stationarity testing."

Wrong. Lag features encode temporal dependency but do not automatically induce stationarity. A series with strong trend will still have non-constant mean even after adding lags. Always test for stationarity explicitly.

### Interpretation 2

>[!Warning]
> "Rolling means with large windows always improve forecasts."

Wrong. Excessively large windows introduce lag and obscure recent changes. The optimal window balances noise reduction against responsiveness. It should be determined through cross-validation, not assumed.

### Interpretation 3

>[!Warning]
> "Calendar features are irrelevant for non-human data."

Wrong. Even sensor data may exhibit calendar-driven patterns (e.g., equipment maintenance schedules, building occupancy cycles). Always test whether calendar components add predictive value before discarding them.

## 7.1.10. Factors Affecting Feature Quality

### 10.1 Window Size Selection

Larger $$w$$ in rolling statistics produces smoother features but increases lag. The tradeoff is:

| Goal | Effect of Larger $$w$$ |
|---|---|
| Noise reduction | Stronger smoothing |
| Responsiveness | Increased lag |
| Volatility detection | Reduced sensitivity |

### 10.2 Number of Lags

More lag features capture longer memory but increase dimensionality and risk of multicollinearity. The autocorrelation function (ACF) should guide lag selection:

$$
\text{ACF}(k) = \rho_k = \frac{\sum_{t=k+1}^{n} (Y_t - \bar{Y})(Y_{t-k} - \bar{Y})}{\sum_{t=1}^{n} (Y_t - \bar{Y})^2}
$$

Include lags where $$\rho_k$$ exceeds significance thresholds.

### 10.3 Domain Knowledge Integration

Features derived from domain expertise (RSI, RMSSD) often outperform generic statistical features because they encode theoretically justified relationships. Generic features explore; domain features exploit known structure.

## 7.1.11. Conclusions

Time series feature engineering transforms raw temporal observations into structured predictors that capture memory, trend, seasonality, and volatility.

### 11.1 Anatomy of Time Series Features

The structure of every time series feature set follows:

$$
\text{Feature Vector}_t = \left[ \text{Calendar}_t,\ \text{Lags}_t,\ \text{Rolling}_t,\ \text{Domain}_t \right]
$$

- **Calendar features**: Encode cyclical and periodic patterns

- **Lag features**: Capture temporal dependency and memory

- **Rolling features**: Summarize local behavior and volatility

- **Domain features**: Inject specialized knowledge from the application area

### 11.2 Feature Engineering Pipeline

| Stage | Action | Output |
|---|---|---|
| Extraction | Derive calendar, lag, and rolling features | Expanded feature set |
| Visualization | Plot features against raw series | Validation of quality |
| Selection | Remove redundant or noisy features | Parsimonious predictor set |
| Integration | Format as 2D array | Model-ready input |

### 11.3 Critical Principles

Understanding the temporal nature of the data is essential:

- **Order matters**: Temporal sequence carries information that random sampling destroys

- **Local context matters**: Rolling windows capture recent behavior that global summaries miss

- **Domain matters**: Specialized features (RSI, RMSSD) encode theoretical relationships that generic features cannot discover

>[!Tip]
> "The best time series features combine statistical rigor with domain insight. Rolling statistics reveal what the data says; domain features reveal what the expert knows."

You are now equipped with the conceptual foundation to engineer features from temporal data. The next step is implementing formal stationarity testing (such as the Augmented Dickey-Fuller test) to ensure your engineered features meet the assumptions required by standard forecasting and classification models.
