# 7.1.5. Lag Features

Lag features create memory by shifting the target or predictor variables backward in time.

### 5.1 Construction of Lag Features

For a series $$Y_t$$, the lag- $$k$$ feature is:

$$
Y_{t-k}^{\text{(lag)}} = Y_{t-k}
$$

Common lag choices include:

| Lag | Rationale | Use Case |
|---|---|---|
| $$t-1$$ | Immediate past | Short-term dependency |
| $$t-3$$ | Recent history | Medium-term smoothing |
| $$t-7$$ | Same day last week | Weekly seasonality |

### 5.2 Handling Missing Values

Shifting creates initial NaN values because there is no data before the series begins. For lag-$$k$$, the first $$k$$ observations become missing:

$$
Y_1^{\text{(lag-3)}} = \text{NaN}, \quad Y_2^{\text{(lag-3)}} = \text{NaN}, \quad Y_3^{\text{(lag-3)}} = \text{NaN}
$$

These must be handled through:

- dropping the incomplete rows

- forward-filling with available values

- imputing with the series mean or median

>[!Tip]
> The number of lag features to create depends on the autocorrelation structure. Examine the autocorrelation function (ACF) plot to identify which lags carry significant signal.
