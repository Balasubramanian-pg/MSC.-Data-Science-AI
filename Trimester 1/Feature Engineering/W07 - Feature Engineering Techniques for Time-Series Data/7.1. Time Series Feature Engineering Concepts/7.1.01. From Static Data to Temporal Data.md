# 7.1.1. From Static Data to Temporal Data

Statistical modeling assumes that observations carry information.

In traditional tabular data, each row is independent. We model relationships like:

$$
Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \epsilon_i
$$

where:

- $$Y_i$$= response variable for observation$$i$$

- $$X_{1i}, X_{2i}$$ = predictor variables

- $$\epsilon_i$$ = independent error term

- $$i = 1, 2, \dots, n$$

This independence assumption collapses in time series data. Each observation $$Y_t$$is indexed by time$$t$$, and the value at time $$t$$ depends on values at earlier times. The fundamental difference is temporal dependency.

>[!Note]
> In time series, the order of observations is itself information. Shuffling the data destroys the signal.
