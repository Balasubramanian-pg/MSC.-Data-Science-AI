# 7.1.10. Factors Affecting Feature Quality

### 10.1 Window Size Selection

Larger $$w$$ in rolling statistics produces smoother features but increases lag. The tradeoff is:

| Goal | Effect of Larger $$w$$ |
|---|---|
| Noise reduction | Stronger smoothing |
| Responsiveness | Increased lag |
| Volatility detection | Reduced sensitivity |

### 10.2 Number of Lags

More lag features capture longer memory but increase dimensionality and risk of multicollinearity. The autocorrelation function (ACF) should guide lag selection:

$$
\text{ACF}(k) = \rho_k = \frac{\sum_{t=k+1}^{n} (Y_t - \bar{Y})(Y_{t-k} - \bar{Y})}{\sum_{t=1}^{n} (Y_t - \bar{Y})^2}
$$

Include lags where $$\rho_k$$ exceeds significance thresholds.

### 10.3 Domain Knowledge Integration

Features derived from domain expertise (RSI, RMSSD) often outperform generic statistical features because they encode theoretically justified relationships. Generic features explore; domain features exploit known structure.
