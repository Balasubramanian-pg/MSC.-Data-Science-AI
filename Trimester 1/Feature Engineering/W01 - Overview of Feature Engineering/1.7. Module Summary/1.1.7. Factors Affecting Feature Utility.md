# 1.1.7. Factors Affecting Feature Utility

### 1.7.1 Signal-to-Noise Ratio

Features with low signal-to-noise ratios introduce variance without adding predictive power. 

Thus:

- higher model variance

- slower convergence

- degraded generalization

### 1.7.2 Multicollinearity

Highly correlated features inflate model variance and destabilize coefficient estimates in linear models. 

This redundancy forces the model to distribute weight arbitrarily across identical signals.

### 1.7.3 Scale Discrepancy

Features measured on vastly different scales dominate distance-based algorithms like K-Nearest Neighbors. 

The following table summarizes how these factors impact overall model performance.

| Factor | Impact on Variance | Impact on Convergence |
|----------|:---:|---:|
| Signal-to-Noise Ratio | High | Slow |
| Multicollinearity | Very High | Unstable |
| Scale Discrepancy | Medium | Very Slow |

Avoiding these pitfalls ensures your feature space remains mathematically sound.
