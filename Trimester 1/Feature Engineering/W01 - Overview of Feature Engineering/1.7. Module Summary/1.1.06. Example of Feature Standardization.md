# 1.1.6. Example of Feature Standardization

Suppose:

- Dataset: Wine Quality feature matrix

- Raw feature: `fixed acidity` with values $$x = [7.4, 7.8, 7.8]$$

- Computed mean: $$\mu = 7.66$$

- Computed standard deviation: $$\sigma = 0.23$$

- Objective: Standardize the feature to zero mean and unit variance

### Step 1: Compute the Mean

Calculate the average value of the raw feature using the formula:

$$
\mu = \frac{\sum x_i}{n} = 7.66
$$

### Step 2: Compute the Standard Deviation

Calculate the dispersion of the feature values using the formula:

$$
\sigma = \sqrt{\frac{\sum (x_i - \mu)^2}{n}} = 0.23
$$

### Step 3: Apply the Standardization Formula

Transform the first raw value $$x_1 = 7.4$$ using the core standardization equation:

$$
z_1 = \frac{x_1 - \mu}{\sigma}
$$

### Step 4: Calculate the Standardized Score

Substitute the computed parameters into the equation:

$$
z_1 = \frac{7.4 - 7.66}{0.23} = -1.13
$$

### Step 5: Final Result

The standardized feature vector is now centered at zero with unit variance, ready for model ingestion.

Execution is only half the battle; understanding the variables that impact feature utility is what separates robust models from fragile ones.
