# 1.1.5. Overview of Core Engineering Techniques

To manage high-dimensional complexity and maximize signal, a structured toolkit of engineering techniques is required.

### 1.5.1 Data Cleaning

Handling missing values through imputation or removal ensures the mathematical stability of the feature space. Null values break distance calculations and gradient descent algorithms.

### 1.5.2 Encoding

Transforming categorical data using Label, One-Hot, or Ordinal encoding converts non-numeric attributes into a format algorithms can process. This step is mandatory for linear models and neural networks.

### 1.5.3 Scaling

Normalizing ranges via Min-Max scaling or standardization prevents dominant features from skewing the model's optimization landscape. 

### 1.5.4 Extraction and Construction

Creating new variables exposes nonlinear relationships that raw data hides. This includes date parsing, interaction terms, and domain-specific ratios.

### 1.5.5 Selection and Reduction

Using correlation analysis or Principal Component Analysis (PCA) prunes irrelevant features to simplify the model. This directly combats the curse of dimensionality.

Understanding the theory is useless without practical execution.
