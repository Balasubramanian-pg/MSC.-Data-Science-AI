# 1.4.6. Example of Feature Importance Evaluation

Suppose:

- Dataset: Wine Quality physicochemical measurements

- Target: Quality rating from 3 to 8

- Objective: Identify the top chemical drivers of quality and prune irrelevant features

### Step 1: Compute Linear Correlations
Calculate the Pearson correlation coefficient for all features against the target quality score using the formula:

$$
r = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \sum (y_i - \bar{y})^2}}
$$

### Step 2: Visualize Class Distributions
Generate box plots for the top correlated features to verify that their distributions separate cleanly across the discrete quality ratings.

### Step 3: Standardize the Feature Space
Apply the standardization transformation to all continuous variables using the formula:

$$
z = \frac{x - \mu}{\sigma}
$$

### Step 4: Train the Ensemble Model
Fit a Random Forest Classifier on the standardized data and extract the feature importance attributes to rank the variables by their contribution to predictive accuracy.

### Step 5: Prune Low-Importance Features
Remove features with negligible importance scores, such as Free Sulfur Dioxide and Citric Acid, to simplify the model and reduce training time.

Execution is only half the battle; understanding the variables that impact feature utility is what separates robust models from fragile ones.
