# 1.6.2. Data Preprocessing and Cleaning

Before we can engineer features, we must ensure the underlying data is mathematically sound. Missing values break distance calculations and gradient descent algorithms.

Handling missing data involves filling gaps using statistical measures like the mean, median, or mode, or removing rows and columns that exceed a specific threshold of missing values.

The imputation process for a missing value $$x_{i,j}$$in column$$j$$ replaces the null with the column's central tendency:

$$
x_{i,j} \leftarrow \text{median}(X_j)
$$

where:

- $$x_{i,j}$$= the imputed value for row$$i$$ and column $$j$$

- $$X_j$$= the set of all non-null values in column$$j$$

This maintains data integrity without discarding valuable observations.
