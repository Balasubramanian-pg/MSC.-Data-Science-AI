# 1.6.3. Encoding Categorical Variables

Algorithms cannot process text. We must convert non-numeric categories into machine-readable numerical formats.

Label Encoding assigns a unique integer to each category. This is efficient for ordinal data where order matters.

One-Hot Encoding creates separate binary columns for each category. This prevents the model from assuming a mathematical relationship between unrelated categories.

Ordinal Encoding retains inherent order, mapping categories to a sequential numerical scale.

The One-Hot Encoding transformation for a categorical variable $$C$$with$$k$$ unique classes expands the feature space dimensionally:

$$
\text{Dim}(X_{\text{new}}) = \text{Dim}(X_{\text{old}}) + k - 1
$$

where:

- $$k$$= number of unique categories in variable$$C$$

- $$\text{Dim}$$ = the total number of features in the dataset

Let us reiterate the dimensional expansion formula, as it is critical for managing memory:

$$
\text{Dim}(X_{\text{new}}) = \text{Dim}(X_{\text{old}}) + k - 1
$$

With categorical data translated, we must address the scale of our numerical features.
