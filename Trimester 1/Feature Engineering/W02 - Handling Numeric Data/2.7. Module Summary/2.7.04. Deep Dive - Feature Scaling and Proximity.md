# 2.7.4. Deep Dive: Feature Scaling and Proximity

Scaling is essential for algorithms where geometric proximity drives predictive power. 

Min-Max scaling maps data to a strict bounded interval. The transformation for a raw value $$x$$ is defined as:

$$
x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
$$

where:

- $$x_{\text{scaled}}$$ = the normalized value within the bounded range

- $$x$$ = the raw feature value

- $$x_{\min}$$ = the absolute minimum value observed in the feature

- $$x_{\max}$$ = the absolute maximum value observed in the feature

This method is highly sensitive to outliers, as a single extreme value will compress all legitimate data into a microscopic range.

Standardization, or Z-Score scaling, centers data at a mean of zero with a standard deviation of one. The transformation is defined as:

$$
z = \frac{x - \mu}{\sigma}
$$

where:

- $$z$$ = the standardized feature value

- $$\mu$$ = the arithmetic mean of the feature

- $$\sigma$$ = the standard deviation of the feature

Standardization is robust to outliers and remains the preferred technique for many linear estimators and distance-based models.

Let us reiterate the core standardization formula, as it is the bedrock of numerical alignment:

$$
z = \frac{x - \mu}{\sigma}
$$
