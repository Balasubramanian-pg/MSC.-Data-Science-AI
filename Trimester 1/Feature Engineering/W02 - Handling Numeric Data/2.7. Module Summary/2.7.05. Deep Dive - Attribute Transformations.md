# 2.7.5. Deep Dive: Attribute Transformations

When data is heavily skewed, models often struggle to interpret the signal hidden within the long tails.

Logarithmic and power transforms compress the range of large values, pulling extreme outliers closer to the mean and creating a more symmetric distribution. 

The log-one-plus transformation is defined as:

$$
x_{\text{log1p}} = \log(1 + x)
$$

where:

- $$x_{\text{log1p}}$$ = the transformed feature value

- $$x$$ = the raw feature value

This is essential for converting exponentially growing data into a linear or normal-like format, ensuring that the model does not over-index on massive outliers.
