# 2.7.2. The Core Toolkit for Numeric Transformation

To manage the complexities of numeric data, we deploy a structured toolkit of preprocessing techniques. 

The following table outlines the primary techniques, their core objectives, and their optimal use cases within the machine learning pipeline.

| Technique | Primary Purpose | Best Used For |
| :--- | :--- | :--- |
| **Discretization** | Convert continuous data into discrete intervals or bins. | Capturing nonlinear relationships and improving interpretability. |
| **Feature Scaling** | Ensure all features exist on a comparable mathematical scale. | Distance-based and gradient-based algorithms. |
| **Attribute Transformation** | Reshape distributions to correct skewness and handle outliers. | Making data more symmetric to satisfy linear model assumptions. |
| **Smoothing** | Remove random noise and highlight underlying temporal trends. | Time-series data and high-frequency fluctuations. |

With the toolkit defined, we must examine the mathematical mechanics of each technique.
