# 2.7.7. The Geometry of Scale and Proximity Metrics

The module emphasizes a critical finding: proximity metrics are strictly scale-dependent. 

If a feature like Income is used alongside Age without scaling, the Euclidean distance calculation will effectively ignore Age. Proper engineering prevents this feature dominance, ensuring that every variable is evaluated on its predictive merit rather than its unit of measurement.

The Euclidean distance between two points $$p$$ and $$q$$ is defined as:

$$
d(p, q) = \sqrt{\sum_{i=1}^{n} (q_i - p_i)^2}
$$

where:

- $$d(p, q)$$ = the Euclidean distance between points $$p$$ and $$q$$

- $$n$$ = the total number of dimensions or features

- $$p_i$$ = the value of the $$i$$-th feature for point $$p$$

- $$q_i$$ = the value of the $$i$$-th feature for point $$q$$

Let us reiterate the core Euclidean formula, as it is the foundation of all distance-based modeling:

$$
d(p, q) = \sqrt{\sum_{i=1}^{n} (q_i - p_i)^2}
$$

Understanding the theory is useless without practical execution.
