# 2.3.4. Algorithmic Sensitivity to Scale

Not all algorithms perceive the geometry of the feature space in the same way. The necessity of scaling is strictly dictated by the mathematical mechanics of the model.

Distance-based algorithms, such as K-Nearest Neighbors, rely entirely on Euclidean or Manhattan distance. If the features are unscaled, the distance calculation is dominated by the feature with the largest range.

Gradient-based optimization, used in Logistic Regression and Neural Networks, requires scaled features to ensure the contours of the cost function are spherical. Unscaled features create elliptical contours, causing the gradient descent to bounce erratically and fail to converge.

Conversely, tree-based models like Decision Trees and Random Forests partition the space using local threshold splits. A split such as "Income > 50,000" is mathematically invariant to whether the income is measured in dollars or scaled between zero and one. 

The following table summarizes the algorithmic requirements for feature scaling.

| Algorithm Class | Scaling Requirement | Mathematical Reason |
| :--- | :---: | :--- |
| K-Nearest Neighbors | Mandatory | Relies on global distance metrics |
| Support Vector Machines | Mandatory | Maximizes margin based on distance |
| Logistic Regression | Mandatory | Ensures stable gradient descent |
| Decision Trees | Not Required | Uses ordinal threshold splits |
