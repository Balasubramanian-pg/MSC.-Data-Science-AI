# 2.3.3. Z-Score Standardization

When data contains extreme outliers or follows a Gaussian distribution, bounding it artificially compresses the legitimate variance. Z-score standardization, or standard scaling, solves this by centering the distribution around zero with a unit variance.

The transformation maps a raw value $$x$$ to a standardized score $$z$$:

$$
z = \frac{x - \mu}{\sigma}
$$

where:

- $$z$$ = the standardized feature value

- $$x$$ = the raw feature value

- $$\mu$$ = the arithmetic mean of the feature

- $$\sigma$$ = the standard deviation of the feature

This method does not restrict the data to a specific range. Instead, it transforms the geometry of the feature space so that one unit of distance represents one standard deviation of variance. This is the required transformation for algorithms that assume a normal distribution.

Let us reiterate the core standardization formula, as it is the bedrock of numerical alignment:

$$
z = \frac{x - \mu}{\sigma}
$$
