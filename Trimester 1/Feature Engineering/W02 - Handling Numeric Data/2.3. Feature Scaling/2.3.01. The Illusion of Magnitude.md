# 2.3.1. The Illusion of Magnitude

Machine learning algorithms work with numbers, not their real-world meaning. An age of 50 and an annual income of 500,000 are simply numerical values. Without scaling, features with larger numerical ranges naturally have a greater influence on the model, even if they are less important predictors.

For many algorithms, especially those based on distance or gradient optimization, this difference in scale can bias the learning process. Variables measured in larger units can dominate calculations, causing smaller-scale features to contribute very little.

Feature scaling addresses this issue by transforming numerical variables to a common scale while preserving the relationships between observations. This ensures that each feature contributes based on its predictive value rather than its magnitude or unit of measurement.

Scaling is particularly important for algorithms such as K-Nearest Neighbors (KNN), K-Means Clustering, Support Vector Machines (SVM), Principal Component Analysis (PCA), and Neural Networks. Although tree-based models are generally unaffected by feature scale, scaling remains a standard preprocessing step for many machine learning workflows.
