# 2.3.5. Example of Min-Max Normalization

Suppose:

- Dataset: Customer demographic records

- Raw feature: `Age` with values ranging from 18 to 90

- Specific value to scale: $$x = 30$$

- Computed minimum: $$x_{\min} = 10$$

- Computed maximum: $$x_{\max} = 50$$

- Objective: Normalize the age value to a zero-to-one range

### Step 1: Define the Boundary Parameters
Identify the absolute minimum and maximum values of the continuous feature to establish the total mathematical span.

### Step 2: Calculate the Denominator
Compute the total range of the feature by subtracting the minimum from the maximum:

$$
\text{Range} = x_{\max} - x_{\min} = 50 - 10 = 40
$$

### Step 3: Apply the Min-Max Formula
Transform the specific raw value $$x = 30$$ using the core normalization equation:

$$
x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
$$

### Step 4: Calculate the Normalized Score
Substitute the computed parameters into the equation:

$$
x_{\text{scaled}} = \frac{30 - 10}{40} = \frac{20}{40} = 0.5
$$

### Step 5: Final Result
The standardized feature value is exactly 0.5, placing it perfectly in the center of the bounded unit interval, ready for distance-based model ingestion.
