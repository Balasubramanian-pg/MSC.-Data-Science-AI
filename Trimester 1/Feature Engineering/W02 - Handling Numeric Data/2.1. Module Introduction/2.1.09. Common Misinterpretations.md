# 2.1.9. Common Misinterpretations

Many practitioners fall into predictable traps when handling numeric data, leading to degraded model performance.

### Interpretation 1

>[!Warning]
> **"Standardization is required for all machine learning algorithms."**

Wrong. 

Tree-based models like Random Forests and Gradient Boosting split data based on ordinal ranking, not geometric distance. They are entirely invariant to monotonic feature scaling.

### Interpretation 2

>[!Warning]
> **"Min-Max scaling is always superior because it keeps data strictly bounded."**

Wrong under outlier presence. 

If your dataset contains a single massive outlier, Min-Max scaling will compress 99% of your normal data into a microscopic sliver of the zero-to-one range, effectively destroying their variance.

### Interpretation 3

>[!Warning]
> **"Binning continuous variables always improves model performance."**

Not necessarily. 

While binning reduces overfitting to noise, it permanently destroys the granular signal within each bucket. If the underlying relationship is strictly linear, binning will artificially introduce step-functions and degrade predictive accuracy.
