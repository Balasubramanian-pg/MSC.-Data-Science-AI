# 2.1.7. Example of Feature Standardization

Suppose:

- Dataset: Real estate property records

- Raw feature: `Property Area` in square feet

- Values: $$x = [1200, 1500, 1800, 2100]$$

- Computed mean: $$\mu = 1650$$

- Computed standard deviation: $$\sigma = 300$$

- Objective: Standardize the feature to zero mean and unit variance

### Step 1: Compute the Mean
Calculate the average value of the raw feature using the formula:

$$
\mu = \frac{\sum x_i}{n} = 1650
$$

### Step 2: Compute the Standard Deviation
Calculate the dispersion of the feature values using the formula:

$$
\sigma = \sqrt{\frac{\sum (x_i - \mu)^2}{n}} = 300
$$

### Step 3: Apply the Standardization Formula
Transform the first raw value $$x_1 = 1200$$ using the core standardization equation:

$$
z_1 = \frac{x_1 - \mu}{\sigma}
$$

### Step 4: Calculate the Standardized Score
Substitute the computed parameters into the equation:

$$
z_1 = \frac{1200 - 1650}{300} = -1.5
$$

### Step 5: Final Result
The standardized feature vector is now centered at zero with unit variance, ensuring the area feature contributes proportionally to the model's distance calculations.
