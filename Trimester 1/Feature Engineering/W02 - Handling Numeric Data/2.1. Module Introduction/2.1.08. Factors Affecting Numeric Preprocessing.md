# 2.1.8. Factors Affecting Numeric Preprocessing

### 8.1 Scale Discrepancy
Features measured on vastly different scales dominate distance-based algorithms.
Thus, the model completely ignores features with smaller numerical ranges.

### 8.2 Outlier Sensitivity
Extreme values exert a massive pull on the mean and variance.
This distorts the standardization process and skews the decision boundaries of linear models.

### 8.3 Distributional Skew
Long-tailed distributions violate the normality assumptions of parametric tests.
This reduces the statistical power of the model and inflates the impact of rare events.

The following table summarizes how these factors impact overall model performance.

| Factor | Impact on Distance Metrics | Impact on Model Variance |
| :--- | :---: | ---: |
| Scale Discrepancy | Very High | High |
| Outlier Sensitivity | High | Very High |
| Distributional Skew | Medium | High |
