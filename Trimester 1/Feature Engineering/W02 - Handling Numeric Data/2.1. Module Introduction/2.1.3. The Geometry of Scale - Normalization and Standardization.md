# 2.1.3. The Geometry of Scale: Normalization and Standardization

To neutralize the arbitrary units of measurement, we must map all features onto a unified mathematical plane. 

Min-Max scaling compresses all values into a fixed boundary, typically between zero and one. This is essential when the algorithm requires strict bounded inputs, such as neural networks relying on sigmoid activation functions.

$$
x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
$$

where:

- $$x_{\text{scaled}}$$ = the normalized value

- $$x$$ = the raw feature value

- $$x_{\min}$$ = the minimum value in the feature

- $$x_{\max}$$ = the maximum value in the feature

Standardization, conversely, does not bound the data. Instead, it centers the distribution around zero with a unit variance. This is the required transformation for algorithms that assume a normal distribution, such as linear regression or principal component analysis.

$$
z = \frac{x - \mu}{\sigma}
$$

where:

- $$z$$ = the standardized score

- $$\mu$$ = the mean of the feature

- $$\sigma$$ = the standard deviation of the feature

Let us reiterate the core standardization formula, as it is the bedrock of numerical alignment:

$$
z = \frac{x - \mu}{\sigma}
$$
