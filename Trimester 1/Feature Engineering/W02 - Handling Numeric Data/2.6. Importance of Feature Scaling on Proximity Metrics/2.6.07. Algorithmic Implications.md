# 2.6.7. Algorithmic Implications

For algorithms like K-Means Clustering or K-Nearest Neighbors, scaling is not an optional enhancement; it is a strict functional requirement.

Without scaling, the clusters identified are merely artifacts of the data's arbitrary units rather than true underlying patterns.

Scaling mitigates dominance by ensuring that every feature contributes proportionally to the total distance calculation.

This levels the playing field, allowing the algorithm to identify neighbors based on true structural proximity.

Understanding the theory is useless without practical execution.
