# 2.6.9. Common Misinterpretations

Many practitioners fall into predictable traps when applying proximity metrics, leading to severely degraded model performance.

### Interpretation 1

>[!Warning]
> "Euclidean distance is invariant to feature scaling."

**Wrong.**

Because the formula squares the differences between coordinates, any change in scale fundamentally alters the magnitude of the squared terms, drastically changing the final distance.

### Interpretation 2

>[!Warning]
> "Scaling should be applied to the entire dataset before the train-test split."

**Wrong under strict evaluation protocols.**

Calculating the minimum, maximum, mean, or standard deviation using the test set introduces severe data leakage. You must fit the scaler exclusively on the training data.

### Interpretation 3

>[!Warning]
> "Min-Max scaling is always superior for K-Nearest Neighbors because it bounds the data."

**Not necessarily.**

If the dataset contains extreme outliers, Min-Max scaling will compress 99 percent of the legitimate data into a microscopic range, effectively destroying the variance required to distinguish between neighbors.
