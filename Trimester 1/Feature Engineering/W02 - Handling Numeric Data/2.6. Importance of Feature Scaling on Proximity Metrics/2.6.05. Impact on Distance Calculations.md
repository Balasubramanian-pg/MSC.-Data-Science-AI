# 2.6.5. Impact on Distance Calculations

When scaling is applied, the Euclidean distance between the exact same two data points changes drastically, reflecting the re-balancing of feature influence.

The following table compares the resulting distance calculations for identical data points across different scaling states.

| Dataset | Metric Calculation State | Resulting Distance |
| :--- | :---: | ---: |
| Breast Cancer | Raw Data | 341.0 |
| Breast Cancer | Min-Max Scaled | 1.5 |
| Breast Cancer | Z-Score Scaled | 10.3 |
| Wine Quality | Raw Data | 2.9 |
| Wine Quality | Min-Max Scaled | 2.3 |
| Wine Quality | Z-Score Scaled | 2.5 |

The dramatic reduction in distance for the Breast Cancer data occurs because Min-Max normalization successfully reined in highly volatile features that were previously inflating the raw distance.
