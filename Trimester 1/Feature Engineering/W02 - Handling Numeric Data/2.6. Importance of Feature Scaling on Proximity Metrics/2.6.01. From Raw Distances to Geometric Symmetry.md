# 2.6.1. From Raw Distances to Geometric Symmetry

Proximity metrics quantify the similarity between data points in a multidimensional space. They serve as the mathematical foundation for distance-based algorithms like K-Nearest Neighbors and K-Means Clustering.

If all features were measured in identical units with identical variances, the raw geometric distance would perfectly reflect true similarity. We would simply calculate the straight-line distance between observations without any preprocessing.

But in real-world datasets, features possess vastly different scales and units of measurement. A feature measured in thousands will mathematically overpower a feature measured in fractions.

Instead of relying on raw coordinates, we must apply scaling transformations to restore geometric symmetry.

From these scaled features, we calculate the proximity metric using the standardized coordinates.

**The scaled distance acts as an unbiased estimator of true similarity.**
