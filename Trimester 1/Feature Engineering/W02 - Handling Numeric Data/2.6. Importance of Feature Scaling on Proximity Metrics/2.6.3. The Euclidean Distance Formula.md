# 2.6.3. The Euclidean Distance Formula

The most prevalent proximity metric is the Euclidean distance, which measures the straight-line length between two points in an $$n$$-dimensional space.

Let two data points be defined as $$p$$ and $$q$$. **The Euclidean distance $$d(p, q)$$ is calculated as:**

$$
d(p, q) = \sqrt{\sum_{i=1}^{n} (q_i - p_i)^2}
$$

where:

- $$d(p, q)$$ = the Euclidean distance between points $$p$$ and $$q$$

- $$n$$ = the total number of dimensions or features

- $$p_i$$ = the value of the $$i$$-th feature for point $$p$$

- $$q_i$$ = the value of the $$i$$-th feature for point $$q$$

If one feature has a range of zero to one thousand and another has a range of zero to one, the squared difference of the first feature will completely overwhelm the sum.

Let us reiterate the core Euclidean formula, as it is the foundation of all distance-based modeling:

$$
d(p, q) = \sqrt{\sum_{i=1}^{n} (q_i - p_i)^2}
$$

With the mathematical foundation established, we must observe how scaling alters this geometry.
