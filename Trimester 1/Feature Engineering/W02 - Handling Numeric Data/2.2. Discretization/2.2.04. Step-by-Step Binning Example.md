# 2.2.4. Step-by-Step Binning Example

Suppose:

- Dataset: Banking customer records

- Raw feature: `Age` with values ranging from 18 to 90

- Computed minimum: $$X_{\min} = 18$$

- Computed maximum: $$X_{\max} = 90$$

- Objective: Create 4 equal-width bins to categorize the customers

### Step 1: Define the Range Parameters
Identify the absolute minimum and maximum values of the continuous feature to establish the total mathematical span.

### Step 2: Calculate the Bin Width
Compute the width of each interval using the equal width formula:

$$
W = \frac{X_{\max} - X_{\min}}{k}
$$

### Step 3: Calculate the Specific Width
Substitute the parameters into the equation for $$k = 4$$:

$$
W = \frac{90 - 18}{4} = \frac{72}{4} = 18
$$

### Step 4: Establish the Boundaries
Calculate the cut-off points for each bin using the boundary formula:

$$
\text{Boundary}_i = X_{\min} + i \times W
$$

The boundaries are 18, 36, 54, 72, and 90.

### Step 5: Final Result
The continuous age variable is now partitioned into four discrete intervals: [18-36), [36-54), [54-72), and [72-90], allowing the model to treat each life stage as a distinct categorical predictor.

Execution is only half the battle; understanding the variables that impact binning efficacy is what separates robust models from fragile ones.
