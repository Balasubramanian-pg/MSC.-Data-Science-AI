# 2.2.5. Factors Affecting Binning Efficacy

### 5.1 Information Loss

Binning permanently destroys the granular variance within each bucket.

Thus, the model can no longer distinguish between a 36-year-old and a 53-year-old if they fall into the same bin.

### 5.2 Boundary Sensitivity

The placement of bin edges can artificially create or destroy patterns.

A slight shift in the boundary might separate two identical data points into different categories, introducing discontinuous step-functions into the model's predictions.

### 5.3 Sparsity in High Dimensions

If you bin multiple continuous variables and then apply one-hot encoding, the feature space will explode combinatorially.

This leads to severe data sparsity and the curse of dimensionality.

The following table summarizes how these factors impact overall model performance.

| Factor | Impact on Model Variance | Impact on Interpretability |
| :--- | :---: | ---: |
| Information Loss | Medium | High |
| Boundary Sensitivity | High | Low |
| Sparsity in High Dimensions | Very High | Low |
