# 2.2. Discretization and Binning in Feature Engineering

Discretization, or **binning**, is the process of converting a continuous numerical feature into a set of discrete intervals or categories. Instead of using the raw numerical values, observations are grouped into meaningful ranges.

This technique simplifies the feature, reduces the impact of noise and outliers, and helps machine learning models capture nonlinear relationships that may not be evident when using continuous values directly.

## Benefits

* Improves feature interpretability.
* Reduces sensitivity to noise and outliers.
* Captures nonlinear patterns more effectively.
* Creates meaningful groups for analysis and modeling.

## Common Binning Methods

* **Equal-Width Binning:** Divides the value range into intervals of equal size.
* **Equal-Frequency Binning:** Creates bins containing approximately the same number of observations.
* **Domain-Based Binning:** Defines intervals using business rules or subject matter expertise.

## Summary

Discretization is a simple yet effective feature engineering technique that transforms continuous variables into categorical intervals, making data easier to interpret and, in many cases, improving model performance.
