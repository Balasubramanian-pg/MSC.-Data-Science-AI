# 2.2.2. The Mathematics of Binning Strategies

To impose order on continuous variables, we must define the boundaries of our intervals. Let the continuous variable be $$X$$, with a minimum value $$X_{\min}$$ and a maximum value $$X_{\max}$$. We wish to partition this space into $$k$$ discrete bins.

### 2.1. Equal Width Binning

Equal width binning divides the continuous range into intervals of identical mathematical size. The width of each bin, $$W$$, is calculated as:

$$W = \frac{X_{\max} - X_{\min}}{k}$$

where:

- $$W$$ = the width of each bin

- $$X_{\max}$$ = the maximum value in the feature

- $$X_{\min}$$ = the minimum value in the feature

- $$k$$ = the desired number of bins

The boundaries for the $$i$$-th bin are defined as:

$$\text{Boundary}_i = X_{\min} + i \times W$$

where $$i$$ ranges from $$0$$ to $$k$$.

This method is simple and easy to implement, but it suffers from a fatal flaw: it is entirely blind to the actual density of the data. If your data is heavily skewed, equal width binning will result in some bins containing millions of records while others sit completely empty.

Let us reiterate the core width formula, as it is the foundation of uniform partitioning:

$$W = \frac{X_{\max} - X_{\min}}{k}$$

### 2.2. Equal Frequency Binning

Equal frequency binning, or quantile binning, ignores the mathematical range and focuses entirely on the data density. It divides the range such that each bin contains approximately the same number of data points.

The boundaries are determined by the quantiles of the empirical cumulative distribution function. For $$k$$ bins, the boundaries are set at the$$p$$-th quantiles, where:

$$p = \frac{j}{k}$$

where:

- $$p$$ = the percentile threshold for the bin boundary

- $$j$$= the bin index from $$1$$ to $$k-1$$

This method effectively balances the distribution of samples per bin, making it incredibly robust for managing skewed datasets. However, it forces bins of varying widths, which can obscure the actual numerical distance between categories.

With the mathematical strategies defined, we must apply them to real-world scenarios.
