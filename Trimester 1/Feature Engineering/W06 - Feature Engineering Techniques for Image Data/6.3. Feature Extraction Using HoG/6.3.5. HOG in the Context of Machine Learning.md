# 6.3.5. HOG in the Context of Machine Learning

Once the feature vector is constructed, it is typically fed into a linear classifier, such as a Support Vector Machine (SVM).

### 1. The Decision Function
For an input image represented by a HOG vector $$X_{HOG}$$, the SVM classification score is:

$$
f(X_{HOG}) = w^T X_{HOG} + b
$$

where:

- $$w$$ = learned weight vector
- $$b$$ = bias term

### 2. HOG vs. Convolutional Neural Networks (CNNs)
While CNNs perform feature extraction and classification simultaneously:

$$
\text{CNN Feature} = \sigma(W_{conv} * I + b)
$$

HOG is a deterministic, manual feature extractor. The layers in a CNN often learn filters that replicate the behavior of HOG (detecting gradients and edges), but HOG remains a powerful, computationally efficient baseline when labeled training data is limited.
