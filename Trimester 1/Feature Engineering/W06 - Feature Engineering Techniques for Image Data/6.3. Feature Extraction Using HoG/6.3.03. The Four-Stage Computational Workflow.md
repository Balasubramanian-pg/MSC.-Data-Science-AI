# 6.3.3. The Four-Stage Computational Workflow

The construction of the final feature vector follows a strict hierarchical process designed to balance local detail with global robustness.

### 1. Gradient Orientation Binning
The image is subdivided into small spatial regions called cells, typically $$8 \times 8$$ pixels. For each cell, the algorithm creates a histogram of orientation bins (e.g., 9 bins covering $$0^\circ$$ to $$180^\circ$$). 

>[!Note]
> Each pixel in the cell contributes its gradient magnitude $$m(x,y)$$ as a "vote" to the histogram bin corresponding to its orientation $$\theta(x,y)$$. This binning process provides robustness to minor spatial shifts.

### 2. Block Normalization
To mitigate the effects of illumination intensity, such as shadows or overexposure, cells are grouped into larger, overlapping windows called blocks (e.g., $$2 \times 2$$ cells). The local histograms are concatenated and normalized.

### 3. Normalization Formula
The block vector $$v$$ is normalized using the L2-norm:

$$
v_{normalized} = \frac{v}{\sqrt{\|v\|^2_2 + \epsilon^2}}
$$

where:

- $$\|v\|_2$$ is the L2-norm: $$\sqrt{\sum_{i=1}^{n} v_i^2}$$.
- $$\epsilon$$ is a small constant (the "soft-clipping" value) added to ensure numerical stability against division by zero.

### 4. Feature Vector Concatenation
The final HOG feature vector is produced by concatenating all normalized block histograms. This resulting vector serves as a robust, high-dimensional signature of the image's structural edges.
