# 6.1.4. Example: Applying Canny Edge Detection

Suppose:

- Input image: grayscale photograph, $$512 \times 512$$ pixels

- Gaussian smoothing: $$\sigma = 1.4$$

- Sobel kernels: $$3 \times 3$$

- High threshold: $$T_{\text{high}} = 200$$

- Low threshold: $$T_{\text{low}} = 100$$

### Step 1: Noise Reduction

Apply Gaussian convolution with $$\sigma = 1.4$$:

$$
I_s(x, y) = \sum_{u=-4}^{4} \sum_{v=-4}^{4} I(x+u, y+v) \cdot G(u, v; \sigma=1.4)
$$

### Step 2: Gradient Calculation

Compute Sobel gradients:

$$
G_x(x, y) = (I_s * S_x)(x, y), \quad G_y(x, y) = (I_s * S_y)(x, y)
$$

$$
M(x, y) = \sqrt{G_x(x, y)^2 + G_y(x, y)^2}
$$

$$
\theta(x, y) = \arctan\left(\frac{G_y(x, y)}{G_x(x, y)}\right)
$$

### Step 3: Non-Maximum Suppression

For each pixel, compare $$M(x, y)$$ to neighbors along $$\theta(x, y)$$:

$$
M_{\text{nms}}(x, y) = \begin{cases} M(x, y) & \text{if local maximum} \\ 0 & \text{otherwise} \end{cases}
$$

### Step 4: Double Thresholding

Classify each pixel:

| Magnitude Range | Classification |
|---|---|
| $$M_{\text{nms}} \geq 200$$ | Strong Edge |
| $$100 \leq M_{\text{nms}} < 200$$ | Weak Edge |
| $$M_{\text{nms}} < 100$$ | Non-Edge |

### Step 5: Hysteresis Thresholding

Trace connected components:

- Starting from each Strong Edge pixel, follow 8-connected Weak Edge neighbors

- Promote connected Weak Edges to Strong Edges

- Suppress unconnected Weak Edges to zero

Final output: binary edge map where edge pixels = 255 and non-edge pixels = 0.
