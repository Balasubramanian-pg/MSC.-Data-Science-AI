# 6.1.1. From Raw Pixels to Structural Boundaries

Computer vision begins with arrays of numbers.

A digital image is a two-dimensional grid of pixel intensity values. For a grayscale image of height $$H$$ and width $$W$$, the raw data is:

$$
I(x, y), \quad x = 1, 2, \dots, W; \quad y = 1, 2, \dots, H
$$

where:

- $$I(x, y)$$= intensity at pixel coordinate$$(x, y)$$

- $$I(x, y) \in [0, 255]$$ for 8-bit grayscale images

- $$x$$ = horizontal column index

- $$y$$ = vertical row index

This raw intensity is a **point measurement** of light at a single spatial location. It contains no information about boundaries, shapes, or structures. A model trained on raw pixel values alone would miss the geometric relationships that define objects in the visual world.

The solution is **edge detection**: identifying locations in the image where intensity changes abruptly, indicating the boundary between distinct regions or objects.
