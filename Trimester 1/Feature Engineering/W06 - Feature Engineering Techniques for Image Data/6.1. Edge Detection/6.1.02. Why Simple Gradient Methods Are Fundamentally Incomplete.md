# 6.1.2. Why Simple Gradient Methods Are Fundamentally Incomplete

Suppose two algorithms process the same image.

- Algorithm A computes the raw gradient magnitude at each pixel and thresholds it

- Algorithm B applies noise reduction, non-maximum suppression, and hysteresis linking

Algorithm B's output will almost certainly contain cleaner, more meaningful boundaries.

This happens because raw gradients are corrupted by **sensor noise**, **texture variation**, and **illumination changes**. The key insight is:

>[!Note]
> An edge is not merely a point of high gradient. It is a coherent boundary structure that must be thin, continuous, and robust to noise.

That means edge detection is a structured inference problem, not a simple pixel-wise operation. The gradient magnitude at a single pixel has its own probability distribution conditional on neighborhood structure. Context matters.
