# 6.2.2. Why Edge Detection Alone Is Fundamentally Incomplete

Suppose two algorithms analyze the same image.

- Algorithm A extracts only edge maps

- Algorithm B extracts both edges and corner points

Algorithm B can establish point correspondences between images; Algorithm A cannot.

This happens because edge points are ambiguous under translation. A point on a straight edge could correspond to infinitely many points on a matching edge in another image. The key insight is:

>[!Note]
> An edge point is not a unique landmark. A corner point is. The intersection of edges creates a distinctive feature that can be matched across images.

That means the neighborhood around a corner has its own characteristic structure tensor that distinguishes it from both flat regions and edge points. The local intensity pattern is the signal.
