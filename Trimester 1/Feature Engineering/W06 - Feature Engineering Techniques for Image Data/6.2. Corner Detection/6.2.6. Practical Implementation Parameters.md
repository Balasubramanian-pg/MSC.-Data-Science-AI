# 6.2.6. Practical Implementation Parameters

### 6.1 Harris Corner Detection Parameters

| Parameter | Symbol | Description | Typical Value |
|---|---|---|---|
| Block size | — | Size of neighborhood for structure tensor | 2 to 7 pixels |
| Sobel kernel size | $$k_{\text{size}}$$ | Aperture for gradient computation | 3 or 5 |
| Harris constant | $$k$$ | Empirical parameter in response formula | 0.04 to 0.06 |

### 6.2 Shi-Tomasi Corner Detection Parameters

| Parameter | Symbol | Description | Typical Value |
|---|---|---|---|
| Maximum corners | $$N_{\max}$$ | Upper limit on detected corners | 25 to 100 |
| Quality level | $$q$$ | Minimum acceptable response as fraction of maximum | 0.01 to 0.10 |
| Minimum distance | $$d_{\min}$$ | Minimum Euclidean distance between corners | 5 to 20 pixels |

The minimum distance parameter is particularly important. It prevents clustered detections by enforcing spatial separation:

$$
\|\mathbf{p}_i - \mathbf{p}_j\|_2 \geq d_{\min}, \quad \forall i \neq j
$$

where $$\mathbf{p}_i = (x_i, y_i)$$is the coordinate of the$$i$$-th detected corner.
