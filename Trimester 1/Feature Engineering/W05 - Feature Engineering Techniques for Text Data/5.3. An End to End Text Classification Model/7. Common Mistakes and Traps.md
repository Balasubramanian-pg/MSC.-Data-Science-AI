# 7. Common Mistakes and Traps

1. **The Vectorizer Leak:** Calling `fit_transform` on your validation or test sets. The test set will create its own unique vocabulary, resulting in matrix dimension mismatch when passed to the model. 
   * *Fix:* Call `fit_transform` on the training set. Call *only* `transform` on the test set.
2. **Ignoring Vocabulary Bounds (`max_features`):** Allowing the TF-IDF vectorizer to build an unbounded vocabulary can lead to feature matrices with millions of columns. This causes memory crashes and the Curse of Dimensionality. Hard-capping it (e.g., `max_features=3000`) forces the model to use only the most statistically significant words.
3. **Over-cleaning Text:** Removing too much punctuation. In some contexts (like sentiment analysis), exclamation marks (`!!!`) or capitalization (`GREAT`) carry immense signal. Standard preprocessing strips these blindly.
