# 8. Summary & Advanced Roadmap

### Key Takeaways
* An NLP pipeline is a sequential mapping from discrete character sequences to continuous vector spaces, terminating in a mathematical decision boundary.
* TF-IDF balances the local importance of a word with its global rarity.
* Extracting the highest-scoring TF-IDF words from a specific document allows engineers to audit and explain the logistic regression model's predictions.

### Interview Questions
* **Q: Explain why a Logistic Regression model is mathematically suitable for high-dimensional, sparse text data.**
  * *Answer:* TF-IDF matrices are extremely sparse (mostly zeros). Logistic regression scales $O(N \times D)$, efficiently handling sparsity. Furthermore, text data is generally linearly separable in high-dimensional spaces, making complex non-linear kernels unnecessary and prone to overfitting.
* **Q: How would a TF-IDF vector handle an Out-of-Vocabulary (OOV) word during inference?**
  * *Answer:* The `transform` method of `TfidfVectorizer` ignores OOV words entirely. The resulting vector simply has a zero for all known dimensions regarding that specific word.

### Advanced Learning Roadmap
1. **Sublinear TF Scaling:** Replacing TF with $1 + \log(\text{TF})$ to dampen the effect of a word appearing 50 times in a document versus 5 times (it is not 10x more important).
2. **N-Gram TF-IDF:** Combining the N-Gram logic from previous lessons with TF-IDF scoring to capture phrases (e.g., "New York") weighted by rarity.
3. **Word Embeddings (Word2Vec / GloVe):** Transitioning from sparse frequency-based representations to dense, neural semantic representations.
