# 5. Visualizing Interpretability

It is an engineering best practice to visually debug what the classifier is "looking at" when making a decision. Bar charts of TF-IDF scores per document provide immediate insight into model behavior.

```python
def plot_top_tfidf_features(dense_vector, feature_names, top_k=5):
    """Generates a bar plot of the highest scoring TF-IDF words for a single document."""
    top_indices = dense_vector.argsort()[-top_k:][::-1]
    
    words = [feature_names[i] for i in top_indices if dense_vector[i] > 0]
    scores = [dense_vector[i] for i in top_indices if dense_vector[i] > 0]
    
    plt.figure(figsize=(8, 4))
    plt.barh(words[::-1], scores[::-1], color='teal')
    plt.xlabel('TF-IDF Score')
    plt.title('Top TF-IDF Words for Target Document')
    plt.tight_layout()
    plt.show()
