# 12. Mermaid Diagrams

The end-to-end pipeline for transforming raw text into machine-learnable features.

```mermaid
flowchart TD
    A[Raw Text Corpus] --> B[Text Preprocessing]
    B --> C[Lowercasing & Punctuation Removal]
    C --> D[Tokenization]
    D --> E[Stopword Removal & Stemming/Lemmatization]
    E --> F{Vectorization Strategy}
    
    F -->|Lexical / Exact Match| G[CountVectorizer / BoW]
    F -->|Weighted Lexical| H[TfidfVectorizer]
    F -->|Dense Semantic| I[Word2Vec / GloVe / FastText]
    
    G --> J[Sparse Document-Term Matrix CSR]
    H --> J
    I --> K[Dense Document Embedding Matrix]
    
    J --> L[Downstream ML Model e.g., Naive Bayes, XGBoost]
    K --> M[Downstream ML Model e.g., Neural Networks, SVM]
```
