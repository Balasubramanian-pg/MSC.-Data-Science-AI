# 3.6.6. Example of a Sequential Forward Selection Iteration

Suppose:

- Target = Campaign subscription status
- Initial feature space = 15 engineered variables
- Algorithm = Logistic Regression
- Objective = Maximize classification accuracy

### Step 1: Initialize Empty Subset
$$
S = \{\emptyset\}
$$

### Step 2: Evaluate Single Additions
Train the estimator 15 separate times, testing each feature individually.

### Step 3: Calculate Performance Metric
Assume the constructed balance-ratio feature yields the highest cross-validated accuracy at $$0.78$$.

### Step 4: Update Feature Subset
$$
S_{new} = \{\text{Balance\_Ratio}\}
$$

### Step 5: Final Iteration Decision
The algorithm locks the ratio feature and begins Step 2 again with the remaining 14 variables to test pairwise combinations.
