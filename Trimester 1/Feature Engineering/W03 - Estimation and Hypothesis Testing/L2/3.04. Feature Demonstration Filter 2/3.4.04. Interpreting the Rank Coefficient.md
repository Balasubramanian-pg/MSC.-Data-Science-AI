# 3.4.4. Interpreting the Rank Coefficient

Because of the normalization applied in the mathematical formula, Spearman's coefficient strictly operates within a predetermined range. 

The interpretation of the bounded metric provides immediate insight into the relationship's directional consistency:

- **$$+1.0$$**: Perfect positive monotonic relationship. As the ranks in the first variable increase, the ranks in the second variable perfectly increase.
    
- **$$-1.0$$**: Perfect negative monotonic relationship. As the ranks in the first variable increase, the ranks in the second variable perfectly decrease.
    
- **$$0.0$$**: Complete absence of any consistent monotonic trend.
    

These bounds provide a standardized framework for making deterministic decisions during the feature selection process.
