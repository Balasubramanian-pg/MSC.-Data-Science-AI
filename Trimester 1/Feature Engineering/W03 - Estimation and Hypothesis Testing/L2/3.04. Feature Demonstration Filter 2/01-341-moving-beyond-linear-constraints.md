# 3.4.1. Moving Beyond Linear Constraints

In the initial stages of feature engineering, evaluating relationships between variables is a fundamental requirement. 

While certain filter methods rigidly assume a straight-line proportionality between variables, real-world data rarely adheres to perfectly linear patterns. Complex datasets frequently contain non-linear interactions, heavy-tailed distributions, and extreme outliers that distort traditional linear measurements. 

Because of these inherent complexities, data scientists require a robust alternative capable of capturing signal without strictly demanding linear proportionality. This requirement leads directly to rank-based statistical measures.
