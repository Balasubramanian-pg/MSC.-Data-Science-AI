# 8.0.7. FeatureWiz for Automated Feature Selection

Feature generation frequently produces more variables than can realistically be used in a model.

This creates challenges such as:

* overfitting
* multicollinearity
* computational inefficiency
* reduced interpretability

FeatureWiz addresses these issues through automated feature selection.

### 8.0.7.1. SULOV

SULOV stands for:

**Select Uncorrelated Lowest Variance**

Its objective is to remove highly correlated variables before model training.

Suppose:

$$
Corr(X_1,X_2)=0.95
$$

Both variables contain nearly identical information.

FeatureWiz removes redundant variables while preserving predictive strength.

### 8.0.7.2. Recursive XGBoost Elimination

After correlation pruning, FeatureWiz evaluates feature importance using XGBoost.

The process follows:

$$
\text{Train Model}
\rightarrow
\text{Calculate Importance}
\rightarrow
\text{Remove Weak Features}
\rightarrow
\text{Retrain}
$$

The procedure continues until a compact and predictive feature subset remains.

### 8.0.7.3. Why Feature Selection Matters

Feature selection helps achieve:

* reduced dimensionality
* faster training
* lower memory usage
* improved model generalization
* reduced overfitting

> [!Note]
> Feature generation discovers possibilities. Feature selection determines which possibilities are actually useful.
