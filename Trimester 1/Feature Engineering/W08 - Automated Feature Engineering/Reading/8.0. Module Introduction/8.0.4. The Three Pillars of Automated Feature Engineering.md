# 8.0.4. The Three Pillars of Automated Feature Engineering

Modern Automated Feature Engineering is commonly built around three major approaches.

The following table summarizes the core tools and their objectives.

| Tool                         | Focus             | Mechanism                                             | Use Case                  |
| ---------------------------- | ----------------- | ----------------------------------------------------- | ------------------------- |
| Deep Feature Synthesis (DFS) | Relational Data   | Relationship traversal and aggregations               | Retail, CRM, Healthcare   |
| TSFresh                      | Time-Series Data  | Statistical feature extraction and hypothesis testing | Sensors, IoT, Finance     |
| FeatureWiz                   | Feature Selection | Statistical pruning and model-driven ranking          | High-dimensional datasets |

Together, these tools provide a complete pipeline for:

$$
\text{Feature Generation}
\rightarrow
\text{Feature Selection}
\rightarrow
\text{Model Development}
$$
