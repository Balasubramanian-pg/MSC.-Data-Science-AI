# 8.0.8. The Curse of Dimensionality

As the number of features increases, the volume of the feature space grows rapidly.

Conceptually:

$$
\text{Search Space}
\propto
2^p
$$

where:

* $$p$$ = number of features

This exponential growth creates several challenges:

* sparse observations
* increased computational cost
* unstable model estimates
* higher risk of overfitting

Feature selection methods such as FeatureWiz help control this complexity.
