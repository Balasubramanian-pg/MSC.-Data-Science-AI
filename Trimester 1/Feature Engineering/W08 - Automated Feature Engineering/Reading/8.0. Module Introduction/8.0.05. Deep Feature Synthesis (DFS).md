# 8.0.5. Deep Feature Synthesis (DFS)

Deep Feature Synthesis is the foundational algorithm behind Featuretools.

Its purpose is to automatically generate features from relational and transactional datasets.

### 8.0.5.1. Understanding Relational Data

Many real-world systems contain multiple related tables.

Example:

**Customers Table**

| Customer ID | Customer Name |
| ----------- | ------------- |
| 101         | Alice         |
| 102         | Bob           |

**Orders Table**

| Order ID | Customer ID | Amount |
| -------- | ----------- | ------ |
| 1        | 101         | 100    |
| 2        | 101         | 200    |
| 3        | 102         | 300    |

These tables are connected through a foreign key relationship.

DFS automatically traverses these relationships and generates useful features.

Examples include:

$$
\text{SUM(Order Amount)}
$$

$$
\text{COUNT(Orders)}
$$

$$
\text{MEAN(Order Amount)}
$$

### 8.0.5.2. Feature Stacking

The word "deep" in Deep Feature Synthesis refers to stacking multiple transformations together.

Example:

First feature:

$$
\text{SUM(Order Amount)}
$$

Second feature:

$$
\log(\text{SUM(Order Amount)})
$$

Third feature:

$$
\sqrt{\log(\text{SUM(Order Amount)})}
$$

This layered approach allows DFS to discover increasingly complex relationships.

> [!Note]
> Deep Feature Synthesis can automatically generate hundreds or even thousands of candidate features from a relatively small relational database.
