# 8.4.9. Feature Selection as a Statistical Problem

Feature selection is not merely a computational convenience. It is a statistical necessity.

Consider a dataset with $$p$$ features and $$n$$ observations. The model complexity grows with $$p$$, but the information available grows with $$n$$. When $$p$$ is large relative to $$n$$, the risk of overfitting increases dramatically.

The bias-variance tradeoff applies directly:

$$
\text{Expected Prediction Error} = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}
$$

Adding irrelevant features increases variance without reducing bias. Automated selection methods aim to identify the minimal feature set that captures the signal while controlling variance.
