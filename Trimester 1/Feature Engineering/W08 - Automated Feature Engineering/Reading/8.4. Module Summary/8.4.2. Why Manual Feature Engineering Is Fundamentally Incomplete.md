# 8.4.2. Why Manual Feature Engineering Is Fundamentally Incomplete

Suppose two data scientists independently engineer features for the same customer churn dataset.

- Data Scientist A creates: 15 hand-crafted features based on business logic

- Data Scientist B creates: 15 different hand-crafted features based on alternative assumptions

Neither data scientist is necessarily wrong.

This happens because of **heuristic variability**: different analysts make different assumptions about which patterns matter. The key insight is:

>[!Note]
> A feature set is itself a random variable conditional on the analyst's choices.

That means the model's performance depends heavily on which human happened to engineer the features. Automated methods reduce this dependency by systematically exploring a much larger space of possible transformations.
