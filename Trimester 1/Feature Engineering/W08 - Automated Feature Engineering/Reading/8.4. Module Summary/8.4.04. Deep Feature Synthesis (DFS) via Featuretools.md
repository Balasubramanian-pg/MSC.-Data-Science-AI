# 8.4.4. Deep Feature Synthesis (DFS) via Featuretools

Featuretools automates feature generation for **relational and transactional data**.

It operates on entities (tables) and relationships (keys) to synthesize features through two core operations:

- **Aggregation**: Summarize child records per parent (e.g., mean order value per customer)

- **Transformation**: Apply mathematical functions within an entity (e.g., log of a column)

These operations can be **stacked** recursively. For example:

$$
\text{Feature} = \text{Mean}\left(\text{Std}\left(\text{Rolling\_Sum}(X)\right)\right)
$$

where:

- $$X$$ = a raw numeric variable

- $$\text{Rolling\_Sum}(X)$$ = cumulative sum over a window

- $$\text{Std}(\cdot)$$ = standard deviation of the rolling sums

- $$\text{Mean}(\cdot)$$ = mean of those standard deviations

This stacking enables discovery of multi-level patterns that human analysts rarely construct manually.

>[!Tip]
> DFS excels at "tracing" relationships across tables. If your data has parent-child hierarchies (customers → orders → items), Featuretools will automatically aggregate at every level.
