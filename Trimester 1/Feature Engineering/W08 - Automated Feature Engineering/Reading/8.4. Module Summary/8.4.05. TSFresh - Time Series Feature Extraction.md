# 8.4.5. TSFresh: Time Series Feature Extraction

TSFresh addresses **sequential and sensor data** by extracting hundreds of temporal primitives automatically.

It applies statistical hypothesis testing to validate each feature against the target variable, controlling for multiple comparisons.

Common extracted features include:

| Feature Category | Examples | Description |
|---|---|---|
| Basic Statistics | Mean, variance, maximum | Standard distributional summaries |
| Temporal Structure | Autocorrelation, trend | Patterns across time indices |
| Frequency Domain | Fourier coefficients | Periodic behavior in signals |
| Complexity Measures | Entropy, LLE | Information-theoretic properties |

The statistical validation step is critical. TSFresh does not merely generate features; it tests whether each feature is significantly associated with the target, pruning irrelevant candidates before they reach the model.
