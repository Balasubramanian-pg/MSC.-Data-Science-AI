# 8.5.9. Automated Feature Engineering Workflow

A practical machine learning workflow typically follows five stages.

### 8.5.9.1. Step 1: Prepare Data

Define:

- entities
- relationships
- timestamps
- target variable

### 8.5.9.2. Step 2: Generate Features

Use:

- Featuretools
- TSFresh
- custom primitives

to generate candidate variables.

### 8.5.9.3. Step 3: Filter Features

Apply:

- significance testing
- correlation analysis
- Featurewiz
- model importance scores

### 8.5.9.4. Step 4: Train Models

Build predictive models using selected features.

### 8.5.9.5. Step 5: Validate Performance

Evaluate using:

- cross-validation
- holdout testing
- out-of-time validation

>[!Note]
> Feature engineering should always be evaluated on unseen data. Improvements observed only on training data are not evidence of genuine predictive value.
