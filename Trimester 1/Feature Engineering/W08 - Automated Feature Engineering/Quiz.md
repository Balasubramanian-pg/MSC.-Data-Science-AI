# Question 1

Consider a predictive modeling task on a retail sales dataset. You apply AutoFE and see that model accuracy increases from 72% to 84%. What is the most plausible reason for this improvement?

## Options

* AutoFE introduced structured, relevant features derived from original data.
* The training time was reduced.
* The data was cleaned with missing values removed.
* More data was collected.

## Answer

✅ **AutoFE introduced structured, relevant features derived from original data.**

> [!NOTE]
> **Reason**
>
> **Automated Feature Engineering (AutoFE)** automatically creates new, informative features from existing variables. These engineered features can capture hidden relationships and interactions in the data, enabling the model to learn patterns more effectively and thereby improving predictive performance.

# Question 2

Which of the following features is most likely to be generated by Featuretools in a relational dataset involving customers and transactions?

## Options

* Skewness of stock price returns
* Average transaction value per customer
* Number of zero-crossings in a signal
* Entropy of a sensor waveform

## Answer

✅ **Average transaction value per customer**

> [!NOTE]
> **Reason**
>
> **Featuretools** uses **Deep Feature Synthesis (DFS)** to automatically generate aggregate and transformation features across related tables. In a customer-transaction dataset, a common generated feature would be the **average transaction value per customer**, computed by aggregating transaction records at the customer level.

# Question 3

What is the primary statistical method used by TSFresh to filter out irrelevant features?

## Options

* Principal Component Analysis
* Chi-square test
* Hypothesis testing
* Mutual Information

## Answer

✅ **Hypothesis testing**

> [!NOTE]
> **Reason**
>
> **TSFresh** extracts a large number of time-series features and then applies **statistical hypothesis tests** to determine which features are significantly associated with the target variable. Features that fail these tests are discarded as irrelevant.

# Question 4

Which of the following statements correctly describes Deep Feature Synthesis (DFS) in Featuretools?

## Options

* DFS is used to extract time-domain and frequency-domain features from time-series data.
* DFS only works on single-table datasets.
* DFS performs recursive aggregation and transformation across related entities.
* DFS is used for ranking features by model importance.

## Answer

✅ **DFS performs recursive aggregation and transformation across related entities.**

> [!NOTE]
> **Reason**
>
> **Deep Feature Synthesis (DFS)** is the core algorithm in Featuretools. It automatically creates new features by recursively applying **aggregation** and **transformation** operations across multiple related tables, enabling sophisticated feature generation in relational datasets.

# Question 5

Which of the following statements about FeatureWiz is TRUE?

## Options

* It is primarily used for time-series feature extraction.
* It selects and ranks features using model-based importance and correlation filtering.
* It creates new features by stacking aggregations over tables.
* It uses PCA to reduce dimensionality.

## Answer

✅ **It selects and ranks features using model-based importance and correlation filtering.**

> [!NOTE]
> **Reason**
>
> **FeatureWiz** is an automated feature selection library that combines **model-based feature importance techniques** with **correlation filtering** to identify and retain the most relevant predictors while removing redundant features.
